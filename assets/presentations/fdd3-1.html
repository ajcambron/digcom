Opposite or neighboring colors?

Name the color scheme: opposite colors on the wheel = ______; neighboring colors = ______; one hue, many values = ______.
FDD 3.1 · 1 of 3
GUIDED NOTES #1
COMPLEMENTARY / ANALOGOUS / MONOCHROMATIC
Complementary = directly across the wheel. Analogous = next to each other. Monochromatic = one hue, many values.
