# Classroom Tool Guides

Mechanics for running a general classroom tool (not GMetrix/Certiport, not lab imaging) the way this
school actually accesses it — login flow, exact settings, export steps. Not a lesson, not pedagogy;
just the click-by-click so a teacher isn't guessing at export settings five minutes before a class
needs a file out the door.
