Hall Pass

A one-page, letter-size hall pass stamped with today's date, microprinted through every section so an old or copied pass is easy to spot. Fill it in on screen, then print.

  • Date: the "Valid only on" date, the footer date and the microprint all come from the current date (Eastern time) and refresh every 30 seconds, so a page left open overnight is still correct in the morning.
  • Time out fills in with the current time automatically. Type over it to set your own; clear it and it goes back to automatic.
  • Print pass re-stamps the date and time, then opens the print dialog. Only the pass prints, on one letter page, with the gold bands in color (turn on "Background graphics" if your browser asks).
  • Clear fields empties every field for the next student.
// NEWARK HIGH SCHOOL
HALL PASS
// VALID ONLY ON
// STUDENT NAME
// PERIOD
// TEACHER
// TIME OUT
// TIME IN
// DESTINATION
// TEACHER SIGNATURE
ALTERED OR UNDATED PASSES ARE VOID
| RETURN TO CLASS

Google Docs version

Prefer a pass that lives in Google Drive? Download the Apps Script (HallPass.gs). It rebuilds a Google Doc as the same pass, with today's date microprinted through it.

  1. Create a new, blank Google Doc (this Doc becomes the pass).
  2. In the Doc, choose Extensions > Apps Script, delete the starter code, and paste in the contents of HallPass.gs. Save.
  3. Choose the setup function in the toolbar and click Run once. Approve the permissions prompt. This builds today's pass and installs a daily 6 AM refresh.
  4. Reload the Doc. A Hall Pass menu appears:
    • Issue pass now (stamps time out): rebuilds with today's date and the current time in TIME OUT. Use it right before printing.
    • Refresh date only (blank time out): rebuilds with today's date and a blank TIME OUT.
    • Install daily refresh: re-installs the 6 AM trigger if it's ever removed.

The school name, time zone, refresh hour and colors are set at the top of the script, in CFG.
