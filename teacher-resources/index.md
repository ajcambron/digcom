# Teacher Resources

Administrative and procedural guides for running this course — account setup, testing logistics,
and anything else that's for the teacher's use rather than a student-facing lesson. This is
separate from the per-lesson teacher plans (the `-teacher.md` page paired with each lesson,
reachable from that lesson), which stay unlisted; the guides here have no student-facing
counterpart at all, so they're listed normally.
