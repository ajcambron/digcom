# Certification Test Prep
{: .no_toc }

How to move a class from GMetrix practice to a proctored Adobe Certified Professional exam delivered through Certiport Compass Cloud.
{: .fs-6 .fw-300 }

---

## The four guides

| # | Guide | Who does it | Where |
|:--|:------|:------------|:------|
| 1 | [Create a GMetrix classroom]({% link teacher-resources/cert-prep/01-gmetrix-create-classroom.md %}) | Teacher | manage.gmetrix.net |
| 2 | [Join a GMetrix classroom (student)]({% link teacher-resources/cert-prep/02-gmetrix-student-join.md %}) | Student | gmetrix.net |
| 3 | [Register students in Certiport]({% link teacher-resources/cert-prep/03-certiport-register-students.md %}) | Student, then teacher | certiport.com |
| 4 | [Run a Compass Cloud testing session]({% link teacher-resources/cert-prep/04-certiport-compass-cloud-session.md %}) | Proctor (teacher) | certiport.com + Compass Cloud app |

GMetrix and Certiport are two separate systems with separate logins. GMetrix is the practice gym. Certiport is the meet where the times count. Nothing a student does in GMetrix carries over to Certiport, so plan on two account setups.

## Timeline that works

| When | Task | Guide |
|:-----|:-----|:------|
| First week of the unit | Create the GMetrix classroom, students join and take a Training Mode pass | 1, 2 |
| 3 to 4 weeks before exam | Students create Certiport accounts and register for the Adobe program; collect parental consent forms | 3 |
| 2 weeks before | Create the Certiport exam group and add students; confirm vouchers | 3 |
| 1 week before | Confirm Compass Cloud app is installed on every lab machine; students hit 80%+ in GMetrix Testing Mode | 2, 4 |
| 2 to 7 days before | Create the Compass Cloud session | 4 |
| Within 24 hours of the session | **Confirm** the session (unconfirmed sessions auto-cancel 1 hour before start) | 4 |
| Exam day, 5 minutes before | Start the session and unlock candidates | 4 |

## Words that mean different things in each system

| Term | In GMetrix | In Certiport |
|:-----|:-----------|:-------------|
| **Access code** | A code that unlocks practice content for a student. A *classroom code* is an access code tied to a classroom. | A code emailed to the proctor when a Compass Cloud session is created. Students type it into the Compass Cloud app to reach their exam. One code per exam title. |
| **Class / group** | A *Classroom*: content + student roster + code. | An *Exam Group*: a roster of candidates tied to your test center, optionally attached to a session. |
| **Admin** | The teacher's GMetrix Administrator account. | Roles on one Certiport login: Test Candidate, Teacher, Proctor, Organization Administrator. You switch roles from a dropdown. |

**CATC** is a Certiport Authorized Testing Center. Your school is one; that registration is what lets you proctor.
