# Create a GMetrix Classroom
{: .no_toc }

A GMetrix classroom bundles three things: the practice content, a student roster, and one classroom code students redeem to join. Build one classroom per section per exam (for example, *P3 Photoshop*), so reports line up with your gradebook.

## Before you start

- **A GMetrix Administrator account.** Your school or district issues it. Students cannot see manage.gmetrix.net.
- **Licenses in inventory.** A classroom can only hand out content you own. Check **Orders → My Inventory** in the admin site before building. If the Adobe title you want shows zero available, stop here and contact whoever purchases GMetrix for the district.
- **Your roster count** for the section, so you can cap code redemptions.

## Step 1: Sign in and open Classrooms

1. Go to **manage.gmetrix.net** and sign in with your Administrator credentials.
2. Select **Classrooms** in the sidebar.
3. Select **New Classroom** in the upper left.

## Step 3: Enter classroom details

{: start="6"}
6. Fill in the details form:

| Field | What to enter | Recommendation |
|:------|:--------------|:---------------|
| **Name** | What you and students will see | `P3 Photoshop 2026-27`. Period first sorts cleanly. |
| **Identifier** *(optional)* | Custom beginning for the generated classroom code | A short prefix such as `P3PS` so the code is easy to read aloud. |
| **Available Uses** | Maximum number of times the code can be redeemed | Roster count plus 2. A code pasted into a group chat cannot drain your licenses. |
| **Instructors** *(optional)* | Other Administrator accounts who can manage this classroom | Add a co-teacher or your CTE coordinator. |
| **Description** | Short note | Section, school year, exam title. |

{: start="7"}
7. Set capacity to **No Limit** or **Limit** (student count). Use **Limit** with the same number as Available Uses.
8. Select **Create**.

## Step 4: Copy the classroom code

GMetrix generates the code automatically when you select **Create**.

{: start="9"}
9. From **Classrooms**, select **Details** next to the new classroom.
10. On the **Details** tab, copy the classroom code.
11. Post it where students will see it on day one: Schoology update, the board, or a slide. Guide 2 walks students through redeeming it.

## Step 5: Set dates and attempts on the content

{: start="12"}
12. Open the **Content** tab.
13. Select **Edit** (pencil icon) on a content item to set parameters such as start date, end date, and maximum exam attempts.
14. Select **Add Content** to attach more practice exams later without making a new code.

> Leave **Max Attempts** unlimited during the unit. Repetition in Training Mode is the point. If you want a clean "final check" score, have students switch to Testing Mode for their last two attempts rather than capping attempts.

## Step 6: Watch the roster fill

The **Students** tab lists everyone who redeemed the code. If a student cannot redeem (lost device, SSO trouble), select **New Student** on that tab to add them by hand.

## Troubleshooting

| Symptom | Likely cause | Fix |
|:--------|:-------------|:----|
| Content you expected is missing from the picker | No licenses in inventory | Check **Orders → My Inventory**; purchase or reallocate. |
| Student says "code invalid" | Typo, or Available Uses reached | Compare against the Details tab; raise Available Uses if the cap was hit. |
| Two classrooms show up for one student | Student redeemed a second section's code | Remove them from the wrong classroom's **Students** tab. |
