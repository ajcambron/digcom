# Register Students in Certiport
{: .no_toc }

Every student needs their own Certiport account before exam day, registered for the Adobe program. You then gather them into an **Exam Group** so the testing session knows who is coming. Students do Part A; you do Parts B and C.

## Before you start

- **Your Certiport account has the right roles.** You need Teacher or Organization Administrator (for Exam Groups) and Proctor (for [Guide 4]({% link teacher-resources/cert-prep/04-certiport-compass-cloud-session.md %})), all associated with your school's CATC. Your Organization Administrator grants these under **Org Profile → Associations**.
- **Parental consent forms.** CATCs must collect a signed Parental Consent form before any candidate under 18 sits a Certiport exam. Send the form home 3 to 4 weeks out; it is the item most likely to be missing on exam day.
- **Vouchers.** Know whether your school's vouchers sit in the center's pool or will be assigned to individual students. That choice shows up again in Part C and Guide 4.

## Part A: Student creates a Certiport account

Give this a full class period the first time. The form checks names against ID, and fixing a wrong name later takes a support ticket.

### A1. Start the sign-up

1. Go to **www.certiport.com**.
2. Select the blue **Login / Register** button in the top right.
3. Select **Join for free**.
4. Fill in the first screen:

| Field | Notes |
|:------|:------|
| **Country / Region** | United States |
| **Email address** | This becomes the username. See the recommendation below. |
| **Password** | 12 characters minimum. |
| **I agree to the terms…** | Required checkbox. |

10. Select **Register** next to **Adobe** (and any other program the student will test in, such as Microsoft Office Specialist).
11. Read and accept the program's NDA / EULA. The exam will not launch without it.

### A4. Collect usernames

Have each student submit their Certiport **username** (the email) to you through a Schoology assignment or Google Form. You need the exact string for Part B. A spreadsheet with *Last, First, Certiport username, Consent form returned (Y/N)* is the single most useful document on exam day.

## Part B: Teacher creates an Exam Group

An Exam Group is a roster of candidates tied to your CATC. It is optional for Compass Cloud, but it lets you pre-load who is testing and select the group when you create the session.

### B1. Open Exam Groups

{: start="12"}
12. Log in at **www.certiport.com**.
13. Switch your role to **Teacher** (or **Organization Administrator** / **Organization Member**) from the role dropdown.
14. Select the **Exam Groups** tab.
15. Select **Add Exam Group**. If you are associated with more than one testing center, select your CATC first.

### B2. Fill in the Exam Group

{: start="16"}
16. Complete the details:

| Field | Required? | Recommendation |
|:------|:----------|:---------------|
| **Teacher** (dropdown) | Optional | Select yourself so the group shows on your list. |
| **Exam Group Name** | Required | `P3 Photoshop Dec 2026`. Section, exam, month. |
| **Description** | Optional | Room and session time. |
| **Location** | Optional | Lab room number. |
| **Number of Students** | Optional | Roster count. |
| **Status** | Leave **Active** | |
| **Print Exam Results** | Choice | Allow it if you want paper score reports for portfolios. |
| **Allow Open Enrollment** | Only if needed | For candidates testing at multiple CATC locations. Leave off for a single school. |

{: start="17"}
17. **Assign an exam** (optional but recommended): select the **Program** (Adobe), **Language**, and **Exam** the group will take.
18. **Proctors:** select **Use any associated proctor**. This is Certiport's recommended setting and means any proctor tied to your CATC can run the session if you are out.
19. **Access rights** (optional): give a co-teacher **Owner**, **Editor**, or **Viewer** rights.
20. Select **Update** to review, then **Done** to create the group.

## Part C: Vouchers

Compass Cloud charges at the moment you create the session, and it offers two payment methods:

| Payment method | How it works | Use it when |
|:---------------|:-------------|:------------|
| **Center assigned voucher** | Draws unredeemed, unassigned vouchers from your CATC's pool. | Your school or state bought vouchers for the center. Simplest for a whole class. |
| **User assigned voucher** | Uses vouchers already assigned to specific students. Requires the student to be associated with your center. | Students were issued individual vouchers, or a few are paying for a retake. |

A student with an individual voucher code assigns it to themselves: log in as Test Candidate, open **My Exams**, enter the code, and select **Assign Voucher or License To Me**.

**Recommendation:** use **Center assigned voucher** for a full class. It removes 26 chances for a voucher to be assigned to the wrong account.

---

## Alternative: Bulk Registration

Older Certiport guides describe a **Bulk Registration** tab in the Teacher role: choose a language, organization, and optional Exam Group, upload a CSV with the columns `Lastname`, `Firstname`, `StudentID`, `Alternatename`, and select **Register**. Certiport returns a list of new usernames with a temporary password.

{: .warning }
> Verify this tab still exists on your account before planning around it. The procedure predates Certiport's current email-as-username sign-up and 12-character password rule. If it works, have every student change the temporary password at first login, and still have them complete **Part A3** (program registration and NDA).

## Troubleshooting

| Symptom | Likely cause | Fix |
|:--------|:-------------|:----|
| Student not found in Add Additional Users | No account yet, or a typo in the username | Have them log in and read the email on **My Profile**. |
| Name on account is wrong | Entered a nickname | Fix before exam day; name changes after certification are harder. Contact Certiport support if the field is locked. |
| Student forgot password | Common | Password recovery needs the username and the secret question answer. Build in 5 minutes for this on exam day. |
| Student forgot username | Less common, worse | Certiport support has to verify profile details. Your Part A4 spreadsheet prevents this. |
