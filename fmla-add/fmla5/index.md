# Unit 5 | Premiere Pro Module 4: College Basketball Athlete Showreel (Dec 2, 2026 – Jan 4, 2027)

## Introduction

Module 4: an athlete needs a one-minute highlight reel for recruiters and sponsors. You start from a project template, build a story arc, add frame holds and speed ramps, animate lower thirds and text, translate captions, and export multiple deliverables.

This unit replaces the regular Applications of Digital Design Unit 5 lessons while your teacher is on leave. Every class follows the same routine: a stinger, a pace check, then self-paced work in BrainBuffet Premiere Pro.

| | |
|---|---|
| **BrainBuffet videos** | 4.01–4.15 (15 videos, 124:26 of video) |
| **Class periods** | 14 school days on the A/B calendar: 4 formative days plus 3 S days per section |
| **Summative** | the one-minute athlete showreel with animated lower thirds, speed ramps and translated captions, exported in every required format and aspect ratio (including a vertical YouTube Shorts version) |
