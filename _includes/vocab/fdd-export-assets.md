**Asset Export Panel**
: A panel (Window > Asset Export) for collecting objects or artboards you'll export repeatedly,
then batch-exporting all of them at once, each at multiple scales and formats in a single click.

**Use Artboards**
: An option in Illustrator's export dialogs that exports each artboard in the document as its own
separate file, using the artboard's name in the file name — the standard way to export a
multi-artboard document (a sticker sheet, a set of icons) without manually exporting each one.
