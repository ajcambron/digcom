**Drop Shadow**
: An Effect (Effect > Stylize > Drop Shadow) that renders a soft, offset duplicate of an object's
shape behind it to simulate a cast shadow — adjustable for offset distance, blur, opacity, and
color.

**Feather**
: An Effect that fades an object's edges into transparency over a set distance, softening a hard
vector edge without changing the object's actual path data.

**Glow (Inner/Outer)**
: An Effect that adds a soft halo of light either inside an object's edge (Inner Glow) or
radiating outward from it (Outer Glow) — commonly used for neon signage or light-source effects.

**3D and Materials**
: A set of Effects (Extrude & Bevel, Revolve, Rotate) that build the illusion of a
three-dimensional object from a flat 2D path, with adjustable lighting, surface shading, and
material controls — like every other Illustrator effect, it's non-destructive and stays editable
until the object is expanded.
