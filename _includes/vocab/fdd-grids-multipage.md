**Grid**
: An underlying structure of aligned guides (columns, rows, margins) that positions text and
image blocks consistently across a page or across every page of a document.

**Baseline Grid**
: A grid of evenly spaced horizontal lines that text baselines snap to, keeping type aligned
across columns and across facing pages.

**Multi-Page (Multi-Artboard) Document**
: A single Illustrator file containing several artboards, each representing one page of a
publication — Illustrator's lightweight substitute for dedicated page-layout software when a
project doesn't need true auto-flowing text or master-page automation.

**Template / Master Elements**
: Design elements (a grid, a masthead, a folio position) that repeat identically across every
page of a document, so pages feel like part of one consistent publication rather than
unrelated one-offs.

**Live Area**
: The safe zone inside a page's trim edge where essential content should stay, protecting it
from being cut off by trimming or bleed variance.

**Consistency (Style Guide)**
: The practice of applying the same grid, type sizes, colors, and spacing rules across every
page or piece in a set, so the whole reads as one unified design system rather than several
unrelated designs.
