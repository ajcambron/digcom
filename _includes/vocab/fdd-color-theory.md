**Color Mode**
: The system a document uses to define color numerically — most commonly CMYK for print or RGB
for screens. A document's color mode is set when the file is created and affects how colors are
mixed and displayed.

**CMYK**
: Cyan, Magenta, Yellow, and blacK — a subtractive color model used for print, where inks are
combined on a white page to absorb (subtract) light.

**RGB**
: Red, Green, and Blue — an additive color model used for screens, where light is combined to
create color.

**HSB**
: Hue, Saturation, and Brightness — a way of describing a color that often matches how humans
naturally think about color, rather than raw channel percentages.

**Grayscale**
: A color mode using only values of gray, with no hue or saturation at all.

**Hex Values**
: A 6-digit code (like `#2C6E49`) used to specify an RGB color for web and screen work — simply
another way of writing the same RGB color.

**Spot Color**
: A single, precisely pre-mixed ink (such as a specific Pantone shade) printed exactly as
specified, rather than built from a combination of CMYK dots — used when exact, consistent color
matters more than photographic realism (a brand's logo color, for example).

**Rich Black**
: A CMYK mix that adds some Cyan, Magenta, and Yellow to 100% blacK, producing a deeper, denser
black than K alone — useful for large solid-black print areas.
