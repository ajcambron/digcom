**Adjustment Layer**
: A clip that applies its effects to every clip below it in the timeline.

**Anamorphic Crop**
: Cropping the top and bottom of the frame to get a cinematic 2.40:1 look.

**Echo Effect**
: A video effect that leaves ghostly motion trails.

**Export Settings**
: The format, codec, frame size and frame rate used when you output a video.

**Freeform View**
: A Project panel view where you arrange clips by hand, like a storyboard.

**Gain**
: The volume level of an audio clip before it reaches the mix.

**Keyframe**
: A marker that sets a property's value at one point in time, so it can change over time.

**Nesting**
: Putting a sequence inside another sequence so it acts like a single clip.

**Poster Frame**
: The thumbnail image that represents a clip in the Project panel.

**Proxy**
: A low-resolution copy of a video file that makes editing smoother.

**Render Bar**
: The colored bar above the timeline: green is rendered, yellow may play smoothly, red needs rendering.

**Ripple Edit**
: A trim that adds or removes time and slides the following clips to close the gap.

**Rolling Credits**
: A list of names that scrolls up the screen at the end of a film.

**Scene Edit Detection**
: A tool that finds the cuts in a long clip and splits it into separate shots.

**Sync Lock**
: A track setting that keeps tracks in sync when you insert or remove time.

**Vignette**
: Darkening or lightening the edges of the frame to pull the eye toward the center.
