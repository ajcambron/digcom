**Sublayer**
: An item nested inside a layer in the Layers panel — every path, group, or object Illustrator
creates gets its own sublayer automatically. Expand a layer's disclosure triangle to see and
select individual sublayers.

**Stacking Order**
: The front-to-back order objects are drawn in, both within a layer and between layers — items
higher in the Layers panel list draw in front of items below them. Dragging a layer or sublayer
up or down in the panel changes what's visually on top.

**Merge Layers**
: Combining two or more selected layers into one, while keeping each object's relative stacking
order intact — different from **Flatten Artwork**, which collapses *every* layer in the document
into a single layer and can't be limited to a selection.
