**Scale**
: Resizing a clip within the frame. Scaling up beyond 100 percent loses resolution, since the
software is stretching existing pixels rather than adding new detail.

**Rotation**
: Turning a clip around a fixed point, measured in degrees. Small rotations fix a crooked
horizon; large ones are a deliberate stylistic choice.

**Letterboxing**
: Black bars added above and below (or beside) footage to preserve its original aspect ratio when
placed in a differently-shaped frame, instead of stretching or cropping it to fit.

**Generative Expand**
: An AI-based tool that fills in new pixels beyond a clip's original frame edges, useful for
reframing footage into a different aspect ratio without a hard crop.

**Rolling Edit**
: Adjusting the edit point between two adjacent clips, shortening one while lengthening the
other, so the total sequence duration doesn't change.

**Ripple Edit**
: Trimming a clip's length while automatically shifting every clip after it earlier or later in
time to close or maintain the gap.

**Rate Stretch**
: A tool that changes a clip's speed by dragging its edge directly in the timeline, instead of
using a separate speed dialog.

**Time Remapping**
: An effect that lets a clip's speed change gradually or at specific keyframed points within a
single clip, instead of one flat speed for the whole thing.

**Freeze Frame**
: Holding on a single frame of video for an extended duration, stopping all motion while playback
continues.
