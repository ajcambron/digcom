**Generate Vector (Text to Vector Graphic)**
: An Illustrator generative AI feature that produces original, editable vector artwork directly
from a written text prompt, offering several variations to choose from and refine further.

**Prompt Writing**
: The practice of writing a clear, specific instruction for a generative AI tool. Effective
prompts usually name a subject, an art style, and a color palette or mood — vague prompts produce
unpredictable results.
