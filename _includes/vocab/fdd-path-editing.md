**Simplify**
: A command that reduces the number of anchor points on a selected path while preserving its
overall shape — useful for cleaning up a traced or freehand-drawn path that has far more points
than it needs.

**Smooth Tool**
: Reduces jaggedness in a path by redrawing it with fewer, smoother curves as you drag it directly
over the existing path.

**Join**
: Connects two open path endpoints into a single point (as a corner or a smooth point), or closes
an open path into one continuous loop.

**Clean Up**
: A menu command that removes stray points, unpainted objects, and empty text paths left behind
in a document — good housekeeping before finishing a file.

**Outline Stroke**
: Converts a path's stroke into its own closed, fillable vector shape, so a line's thickness
becomes a real shape rather than a stroke setting.

**Offset Path**
: Creates a new path a specified distance inside or outside an existing path — the basis of
common "sticker outline" or nested-line effects.
