**Blend Mode**
: A setting that controls how one layer's pixels mix with the layers below.

**Chroma Key**
: Removing one color (usually green or blue) so another image shows through.

**Drop Shadow**
: A shadow behind text or graphics that makes them easier to read.

**Gaussian Blur**
: A soft blur that reduces detail and sharpness.

**PSD Import**
: Bringing a layered Photoshop file into Premiere Pro.

**Track Matte Key**
: An effect that uses one layer as a matte to control where another layer is visible.

**Typography**
: Arranging type so it is readable and visually appealing.

**Ultra Key**
: Premiere Pro's effect for removing a green or blue screen background.

**Warp Stabilizer**
: An effect that analyzes shaky footage and smooths out camera movement.

**White Balance**
: Correcting color so white objects look white under any kind of light.
