**Sketch**
: A quick, rough drawing used to explore an idea before committing time to it.

**Specifications ("Specs")**
: The exact, measurable requirements a finished design must meet (size, color mode, file
format, etc.).

**Design Process**
: The repeatable sequence of steps — research, sketch, refine, present, revise — a designer
follows from idea to finished work.

**Wireframe**
: A simplified, low-detail layout sketch showing where content and elements will go, without
final styling.

**Prototype**
: An early working model of a design used to test an idea before final production.

**Iteration**
: One cycle of revising and improving a design based on feedback or testing.

**Change Order**
: A documented request to change a project's scope or specs after work has already begun.

**Draft**
: A version of a design that is not yet final and is expected to be revised.

**Feedback Loop**
: The repeating cycle of sharing work, getting feedback, and revising in response to it.

**Style Guide**
: A reference document defining a design's consistent visual rules (colors, fonts, spacing,
logo use, etc.).

**Project Brief**
: A written document that lays out a project's goals, audience, requirements, and constraints
before work begins.
