**B-Roll**
: Extra footage that supports the main shots, like cutaways and background action.

**Effect Presets**
: Saved effect settings you can reuse for consistent results.

**Frame Hold**
: Freezing one frame of a clip for a set time to add emphasis.

**Lower Third**
: A graphic in the lower part of the screen that shows a name, title or hashtag.

**Markers**
: Notes you place on a clip or the timeline to flag a moment or a range.

**Project Manager**
: A tool that collects, copies or trims a project's media into one place.

**Quick Export**
: A fast export that uses default or last-used settings.

**Safety Margins**
: On-screen guides that show where titles and action won't get cut off on different screens.

**Sequence**
: A timeline where you assemble video and audio clips into a finished program.

**Speed Ramping**
: Smoothly speeding up or slowing down a clip for a dramatic effect.

**Story Arc**
: The order of events that builds interest and delivers a clear story.
