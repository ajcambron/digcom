**Restricted Font**
: A licensed font whose terms don't allow its files to be shared or redistributed with a client
or another designer, even inside a project package. Illustrator's Package feature flags these
separately from fonts that are safe to include.

**Model Release / Location Release**
: A signed legal document in which a photographed person (model release) or property owner
(location release) grants permission for their likeness or location to be used in a commercial
project. Required before using a photo containing an identifiable person or a distinctive
private location commercially, regardless of who holds the photo's copyright.

**File Package**
: The folder Illustrator's File > Package command builds automatically, containing a copy of the
document, every linked asset, every font used (where licensing allows), and a summary report —
the standard way to hand a project off to a client or another designer without broken links or
missing fonts.
