**Project Settings**
: The technical specs chosen when a Premiere project is first created—video/audio format,
frame rate, and where render files are stored—set once and rarely changed mid-project.

**Scratch Disks**
: The storage location(s) Premiere uses to save captured media, previews, and cache files while
you work—should point to a fast drive with enough free space, not the same drive as your OS.

**Sequence Presets**
: A pre-built set of sequence settings (frame size, frame rate, codec) matching common camera
formats—picking the preset that matches your footage avoids unnecessary rendering.

**Timecode**
: The frame-accurate address of any point in a clip or sequence, shown as
hours:minutes:seconds:frames (for example, 00:01:23:12)—how editors reference exact moments precisely.

**Project Panel**
: The panel listing every asset (clips, sequences, graphics) imported into a project, organized
into bins—the project's file cabinet.

**Source/Program Monitor**
: Two side-by-side preview windows—the **Source Monitor** shows a raw clip before it's edited
in, the **Program Monitor** shows the sequence as it will actually play back.

**Properties Panel**
: A panel showing the technical metadata (frame rate, resolution, codec, duration) of whatever
clip is currently selected.
