**Dynamic vs. Static Symbol**
: A **Dynamic** symbol allows limited edits to an individual instance (like recoloring it)
without breaking its link back to the master symbol. A **Static** symbol locks every instance
identically to the master — any edit has to be made to the symbol itself, which updates every
instance at once.

**Graphic Style**
: A saved, reusable combination of appearance attributes — fills, strokes, effects, and
transparency — stored in the Graphic Styles panel. Apply the same complex look to any object in
one click; updating the style later updates every object it's applied to.
