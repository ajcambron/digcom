**Anchor Point**
: A fixed point on a vector path — placed by clicking, or click-dragging, with the Pen tool — that
marks where a path changes direction or curvature.

**Segment**
: The straight or curved line connecting two anchor points along a path.

**Corner Point**
: An anchor point where a path changes direction abruptly, with no curve handles (or two
independent handles) on either side.

**Smooth Point**
: An anchor point where a path curves continuously through the point, with linked, symmetrical
direction handles on either side.

**Direction Handle (Direction Line)**
: The lever extending from a smooth anchor point that controls a curve's angle and depth on
either side of the point — dragging it is how you "curve an angle."
