**Align Panel**
: The panel used to line objects up relative to each other, to a key object, or to the artboard —
horizontally (left/center/right) and vertically (top/middle/bottom).

**Distribute**
: Spacing a set of selected objects out evenly — either by equal gaps between them or by equal
center-to-center distance — rather than just lining up one shared edge.

**Key Object**
: The one object in a selection, designated by clicking it a second time, that the rest of the
selection aligns or distributes relative to.

**Stacking Order**
: The front-to-back order in which objects are painted on the artboard — the most recently drawn
object sits on top. Changed with Object > Arrange (Bring to Front, Bring Forward, Send Backward,
Send to Back).

**Group**
: Combining multiple objects (Cmd/Ctrl+G) so they move, scale, and transform together as a single
unit, while still remaining individually editable inside the group.

**Arrange**
: The Object menu command used to change an object's position in the stacking order.
