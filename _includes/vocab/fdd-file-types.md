**.AI (Adobe Illustrator Document)**
: Illustrator's native, fully-editable format — layers, paths, and text all stay live for future
edits.

**.EPS (Encapsulated PostScript)**
: A legacy vector interchange format, still requested by some print vendors and older software;
mostly superseded by .ai and .pdf in modern workflows.

**.PDF (Portable Document Format)**
: A vector-friendly, universally viewable format that can preserve full editability (via
"Preserve Illustrator Editing Capabilities") — often the safest way to hand a file to a client or
printer.

**.SVG (Scalable Vector Graphics)**
: A code-based vector format built for the web — scales to any size with no quality loss, and can
be styled or animated with CSS.

**.PNG (Portable Network Graphics)**
: A raster (pixel-based) format that supports transparency — a common choice for exporting
artwork for screens or web when a raster file is needed.

**.JPG / .JPEG**
: A raster format using lossy compression with no transparency support — small file sizes, common
for photos, not ideal for crisp text or logos.

**Native vs. Interchange Format**
: A native format (like .ai or .psd) keeps all of an application's editable data; an interchange
format (like .eps or .pdf) is built to move a file between different programs or people, sometimes
at the cost of some editability.
