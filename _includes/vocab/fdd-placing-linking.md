**Embedding**
: Placing a raster image into an Illustrator file so its full pixel data is copied directly into
the document. The file grows larger, but it never breaks if the original image moves or is
deleted.

**Linking**
: Placing a raster image as a reference to an external file, which Illustrator displays at
preview resolution but doesn't copy into the document. Keeps the .ai file small, but the link
breaks ("missing") if the original file moves, is renamed, or is deleted.

**Edit Original**
: A command, available on both linked and embedded images, that reopens the original image file
in its source application (e.g. Photoshop) for editing. Save the change there, and the Links
panel shows the placed image updated automatically.
