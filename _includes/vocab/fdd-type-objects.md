**Point Type**
: A single line of text anchored to one point, that keeps growing horizontally as you type unless
you add a manual line break — good for headlines and short labels.

**Area Type**
: Text flowed inside a closed shape (a rectangle, or any custom path), automatically wrapping to
the next line when it reaches the shape's edge — good for paragraphs and body copy.

**Type on a Path**
: Text that flows along the contour of an open or closed path instead of a straight line or a
shape.

**Glyph**
: A specific visual representation of a character — the same letter can have multiple glyph
variants (alternates, ligatures, swashes) within a single font.

**Placeholder Text ("Greeked" Text / Lorem Ipsum)**
: Dummy text used to preview a layout's typography and spacing before final copy has been
written.
