**Composition (Comp)**
: The container or workspace where every layer, effect, and animation in an After Effects project
comes together, the equivalent of a Premiere sequence.

**Layer**
: A single element (text, image, shape, video) inside a composition that can be animated and
manipulated independently of every other layer.

**Anchor Point**
: The fixed point a layer rotates and scales around. Move it off-center and rotation swings
around that new point instead of the layer's middle.

**Precomposing**
: Grouping several layers into a single new composition nested inside the original, so they can
be animated, scaled, or effected together as one unit.

**Render Queue**
: After Effects' export system. Add a composition to the queue, choose render/output settings,
then render, similar to Premiere's Media Encoder but built into the same application.
