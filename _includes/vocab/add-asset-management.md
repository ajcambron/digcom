**Archiving**
: Saving a finished project, including all its media, in an organized state so it can be reopened
and understood months or years later, by you or anyone else.

**Consolidate and Transcode**
: Gathering every media file a project actually uses into one place (consolidate) and converting
it to a standard format (transcode), so an archived project isn't scattered across a dozen
folders in a dozen formats.

**Collect Files**
: Premiere's Project Manager feature that copies every clip a sequence actually uses (and only
those clips) into a new, self-contained project folder.

**Offline Media**
: A clip Premiere can't find, shown as a red placeholder in the timeline, usually because the
original file was moved, renamed, or deleted.

**Naming Convention**
: A consistent, predictable pattern for naming files (LastName_FirstName_Project_v2.mp4) so
anyone on a team, including future you, can tell what a file is without opening it.
