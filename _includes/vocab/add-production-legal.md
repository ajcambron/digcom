**Call Sheet**
: A daily production document listing what's shooting, when, where, and who needs to be there.
The single source of truth for everyone on set that day.

**Shooting Schedule**
: The order scenes actually get filmed in, grouped by location and actor availability, almost
never the same order as the finished story.

**Talent Release**
: A signed document giving a production permission to record and use someone's likeness. Required
for every on-camera performer, even a friend doing a favor.

**Location Release**
: A signed document giving a production permission to film at a specific place. Required for
private property, sometimes required for public spaces depending on what's being filmed.

**Line Item**
: A single row in a budget, one specific expense (gear rental, location fee, catering) tracked
separately so a producer can see exactly where money is going.

**Contingency**
: Extra budget set aside for the unexpected (a reshoot, a broken prop, a rental that runs long).
Industry standard is roughly 10 percent of the total budget.
