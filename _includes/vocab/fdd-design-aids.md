**Outline (view mode)**
: A view mode that displays only the wireframe of every path on the artboard — no fills or
strokes — useful for finding and selecting an object hidden behind another.

**Pixel Preview**
: A view mode that previews how vector artwork will look once rasterized to a screen's pixel
grid — useful when a design is headed for web or screen output.

**Presentation Mode**
: A fullscreen, no-interface slideshow of a document's artboards in order — useful for presenting
work to a client without any Illustrator interface visible.
