**Codec**
: The specific algorithm used to compress and decompress a video file. H.264 and ProRes are both
codecs; "format" (like .mp4 or .mov) is the container the codec's data lives inside.

**Alpha Channel**
: An extra channel in a video file that stores transparency information, letting one clip show
through to whatever's layered beneath it. Required for exporting graphics or effects meant to
composite over other footage.

**Quick Export**
: A one-click export preset in Premiere for fast, simple deliveries when you don't need to
customize settings.

**Batch Processing**
: Queuing multiple exports to run one after another without manual restarts between each one,
essential when a single project needs several delivery versions.

**Queue**
: Adobe Media Encoder's list of pending export jobs, letting Premiere keep editing while exports
render in the background.
