**Slugline**
: The all-caps shot heading that opens a scene (INT./EXT., location, time of day). Tells the crew
where and when a scene happens before a single word of action or dialogue.

**Parenthetical**
: A short direction in parentheses under a character's name, telling an actor how to deliver a
line (whispers), (sarcastic). Used sparingly, overusing them reads as micromanaging the actor.

**Scene Heading**
: Another name for a slugline. INT. KITCHEN - NIGHT is a scene heading.

**Two-Column Script**
: A script format that splits visuals (left column) from audio/dialogue (right column), common
for commercials, music videos, and documentary-style projects instead of standard screenplay
format.

**Beat**
: A pause or turning point in a scene's action or dialogue, marked in a script to control pacing
and give an actor or editor a place to breathe.
