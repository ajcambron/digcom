**Adobe Firefly**
: Adobe's generative AI app for creating images and effects from text prompts.

**Artificial Intelligence (AI)**
: Computer systems that perform tasks like learning, problem-solving and recognizing patterns.

**Asset Export**
: A panel that exports selected artwork as separate files in several formats and sizes at once.

**Business Card**
: A small card with a person's name, job and contact information, used for networking.

**Create Outlines**
: Converting live type into vector shapes so it looks the same on any computer, even without the font.

**Expand**
: Turning a traced or styled object into plain, editable vector paths.

**Generate Vectors**
: An Illustrator generative AI tool that creates editable vector art from a text prompt.

**Generative AI**
: AI that creates new content, such as images or text, from a prompt.

**Generative Shape Fill**
: An Illustrator generative AI tool that fills a shape with vector detail from a prompt.

**Ignore Color**
: An Image Trace option that leaves a chosen color (like a white background) out of the trace.

**Image Trace**
: An Illustrator feature that converts a raster image into vector paths.

**JPG**
: A raster file format for photos. It does not support transparency.

**Mockup**
: An Illustrator feature that previews flat artwork on a 3D object, like a logo on a mug.

**Outline Stroke**
: Converting a stroke into a filled shape so it keeps its thickness when scaled.

**PNG**
: A raster file format that supports transparency.

**Prompt**
: The text description you give generative AI to tell it what to create.

**Share for Review**
: An Illustrator feature that sends a link so others can comment on your design.

**Threshold**
: An Image Trace setting that decides which pixels become black and which become white.

**Trim Marks**
: Small lines printed at the corners that show where to cut the paper.
