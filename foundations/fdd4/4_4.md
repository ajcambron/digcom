Real paths are rarely clean on the first try. Today you'll learn the tools professional
illustrators use constantly to fix, simplify, and combine paths — skills you'll need starting
next class to actually build your S4 piece.

## Direct Instruction — Live Demo (~10 min)

> "Watch what happens to the anchor point count when I run Simplify on this messy path — same
> shape, way fewer points to manage."

The teacher live-demos on a sample low-poly shape:

1. **Simplify** — reducing a messy, over-pointed path.
2. **Join** — connecting two open endpoints into one clean point.
3. **Shape Builder** — dragging across two overlapping facets to merge them into one shape.
4. **Pathfinder Unite / Minus Front** — combining or subtracting shapes with a single click.

{: .discussion }
**Recall:** What does Simplify actually change about a path? **Analysis:** Why might Shape Builder
be faster than Pathfinder for merging just two shapes, but Pathfinder faster for merging many at
once? **Synthesis:** If you had a path with an obvious extra loop of stray points in one corner,
which tool from today would you reach for first, and why?

## Guided Practice — Clean & Combine (~23 min)

{% include worksheet.html file="fdd4-path-refinement-reference" title="Refining Paths Quick Reference" presentation="placeholder" %}

1. **Clean up (~8 min):** open one of your messy practice paths from 4.2. Use **Join** to close any
   open gaps, then run **Simplify** and compare the anchor point count before and after.
2. **Combine facets (~15 min):** draw or reuse 3–4 small low-poly facet shapes. Use the **Shape
   Builder tool** to merge some of them into one larger shape, then try the same merge again using
   **Pathfinder > Unite** to compare the two workflows.

{: .highlight }
Shape Builder merges what you *drag across* — Pathfinder merges *everything currently selected*.
Pick whichever matches how much of the shape you want to combine at once.

## Exit Ticket / Wrap-Up (~5 min)

**Two-Minute Drill:** when your teacher announces go, take one facet you're still working on and
clean it up with any tool from today. Screenshot the before and after.
