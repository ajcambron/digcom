Today you pick up the Pen tool for real. Every low poly facet and every stained-glass panel in
your final piece will be built from the same two moves you'll practice today: placing a **corner
point** and placing a **smooth point**.

## Direct Instruction — Live Demo (~10 min)

> "Watch my hands, not just the screen. A single click places a corner point — sharp, no curve.
> Click *and drag* places a smooth point — see how dragging pulls out these two direction
> handles, and how they control the curve on both sides?"

The teacher live-demos, narrating each click:

1. A **corner-only shape** (e.g. a triangle) — click, click, click, close the path.
2. A **smooth-only curve** (e.g. a wave) — click-drag, click-drag, watching the handles.
3. A **combination path** (e.g. a leaf or shield) mixing both in one shape.

{: .discussion }
**Recall:** What's the physical difference between how you place a corner point versus a smooth
point? **Analysis:** Why do a smooth point's two direction handles move together instead of
independently? **Synthesis/Extension:** How would you draw a shape that's smooth on one side and
sharp on the other, at the very same anchor point?

## Guided Practice — 3 Pen Tool Mini-Tasks (~23 min)

{% include worksheet.html file="fdd4-pen-tool-reference" title="Pen Tool Quick Reference" presentation="placeholder" %}

1. **Corners only (~6 min):** draw a straight-sided shape (triangle, star, or arrow) using only
   corner points.
2. **Curves only (~8 min):** draw a single smooth curve (like a wave or a leaf's outline) using
   only smooth points. Use the **Direct Selection tool** to click back onto a point and adjust its
   handles until the curve looks right.
3. **Combination path (~9 min):** draw one shape combining both corner and smooth points on the
   same path — a leaf, a shield, or a simple low-poly gemstone facet all work well.

{: .highlight }
If a path goes wrong, don't start over — switch to the **Direct Selection tool** (white arrow, A)
and drag the specific point or handle that's off. Fixing one point is faster than redrawing.

## Exit Ticket / Wrap-Up (~5 min)

Screenshot your finished combination path before you close out.

{: .reflection }
Which was harder to control today — corner points or smooth points? Why do you think that is?
