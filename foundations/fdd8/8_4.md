# 8.4 | Generative AI in Illustrator

## Key Terms

{: .vocab }
{% include vocab/fdd-generative-ai.md %}

> Generative AI in Illustrator is a fast way to get a rough starting point — it is not a fast way
> to get a finished, client-ready asset. Today's lesson treats it exactly like that: a sketch,
> not a final answer.

Today you'll use Illustrator's built-in generative AI to turn a written prompt into vector
artwork. Before you use anything it generates in a real project, though — that's next unit's
first lesson, and it matters.

## [10 Mins] Bell Ringer / Hook

{: .discussion }
Here are two AI-generated results from the same tool: one came from the prompt "a bird," the
other from "a small, geometric hummingbird icon in a flat two-color style, teal and orange." Which
one looks more usable, and why?

> "Same tool, wildly different results — because one prompt actually told it what to make."

## [10 Mins] Direct Instruction

**"I Do":** the teacher live-demos, using Illustrator's **Text to Vector Graphic** feature:

1. Entering a vague, one-word prompt and generating results, pointing out how unpredictable and
   generic they look.
2. Rewriting the prompt to name a **subject**, an **art style**, and a **color palette**, and
   regenerating — comparing the noticeably more usable results.
3. Selecting one of the generated variations and opening it in the artboard as real, editable
   vector paths.
4. Hand-editing the result (adjusting a color, deleting or simplifying an element) to show that
   the generated artwork is meant as a **starting point**, not a finished, submittable asset.

{: .highlight }
**Check for Understanding**
**Recall:** "What three things does a strong prompt usually name?"
**Analysis:** "Why did the vague one-word prompt produce such inconsistent results compared to
the detailed one?"
**Synthesis:** "Your S8 sticker pack needs 5 related stickers that all feel like part of one set.
How would you write your prompts to make sure the AI-generated starting points feel consistent
with each other?"

## [23 Mins] Guided Practice

{% include worksheet.html file="generative-ai-reference" title="Generative AI Prompt Reference" presentation="placeholder" %}

1. Write a first prompt naming a subject, a style, and a color palette or mood.
2. Generate variations, then revise your prompt at least once based on what came back.
3. Select your best result and **hand-edit it** — adjust at least one color, shape, or detail so
   it's genuinely different from the raw generated output.
4. **Group prompt swap (5 min):** trade your best prompt with another group; run their prompt
   yourself and compare what you each got back from the identical text.
