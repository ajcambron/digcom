# 8.2 | Symbols & Graphic Styles

{: .vocab }
{% include vocab/fdd-symbols-styles.md %}

> A pattern repeats automatically and can't be nudged one tile at a time. A symbol repeats on
> purpose — and you can still move, scale, or recolor a single instance without breaking the
> others.

Today's tools solve a specific problem: what if you need the same graphic 20 times across a
document, but each one needs to be positioned — or even recolored — independently? That's a
symbol, not a pattern.

## [10 Mins] Bell Ringer / Hook

{: .discussion }
If you needed the same little star icon to appear 12 times on a poster, at different sizes and
rotations, would you copy-paste it 12 times, or is there a smarter way?

> "Copy-paste works until you need to update all 12 at once. Today's answer to that problem is
> the Symbols panel."

## [10 Mins] Direct Instruction

**"I Do":** the teacher live-demos, using a simple original icon:

1. Selecting the icon and dragging it into the **Symbols panel** (or Object > Symbol > New
   Symbol) to create a master symbol, choosing **Dynamic** so instances can be recolored
   independently.
2. Dragging out 3 instances of the symbol, scaling and rotating each one differently.
3. Editing the master symbol (double-clicking to enter isolation mode) and showing every instance
   update at once — except the one instance whose color was changed independently, which keeps
   its own tint thanks to the Dynamic setting.
4. Selecting a finished, styled object and saving it to the **Graphic Styles panel**, then
   applying that saved style to an unrelated object with one click.

{: .highlight }
**Check for Understanding**
**Recall:** "What panel do you drag artwork into to turn it into a reusable symbol?"
**Analysis:** "Why did editing the master symbol update most instances at once, but not the one
I'd recolored?"
**Synthesis:** "You're building an icon set for a client's app — 20 icons that all need to share
the exact same drop-shadow-and-outline look, and the client might ask for a color change later.
Which two tools from today solve that, together?"

## [23 Mins] Guided Practice

{% include worksheet.html file="symbols-styles-reference" title="Symbols & Graphic Styles Reference" presentation="placeholder" %}

1. Draw or reuse a simple icon/shape and save it as a Dynamic symbol.
2. Place at least 3 instances, varying scale and rotation, and recolor at least one instance
   independently.
3. Build a distinct appearance (fill, stroke, effect) on one object and save it as a graphic
   style.
4. Apply that saved style to every instance so your finished set reads as one consistent icon
   family.
