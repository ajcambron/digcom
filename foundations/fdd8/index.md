# Unit 8 | Brushes, Symbols, Patterns & Image Trace

Unit 8 multiplies a single object across a whole surface: brushed strokes and repeating patterns
(8.1), reusable symbols and saved graphic styles (8.2), converting raster source images into
real vector artwork with Image Trace (8.3), and generative AI as a fast (but never final) starting
point (8.4). The unit closes with a sticker pack or merch pattern project combining all four.

## Assessment Rhythm
Each lesson (8.1–8.4) carries its own formative and cycles through Exit Tickets 1–4 in order. On
the S8 project block, students also complete a cumulative vocabulary quiz covering this unit's
terms and receive a grade compiled from the unit's daily bellringers.
