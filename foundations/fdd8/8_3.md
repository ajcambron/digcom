# 8.3 | Image Trace

{: .vocab }
{% include vocab/fdd-image-trace.md %}

> Image Trace doesn't just outline a picture — it rebuilds it as real, scalable vector paths. The
> raster image goes in flat and fixed-resolution; real, editable artwork comes out.

Back in Unit 2 you learned why a raster image gets blurry when it's scaled up, and a vector never
does. Today's tool is the bridge between the two: hand a raster image to Image Trace, and it
builds you an editable vector version.

## [10 Mins] Bell Ringer / Hook

{: .discussion }
Here's a logo, zoomed in twice: one version turns to mush, one stays perfectly crisp. Which one
started as a raster photo, and which one went through Image Trace?

> "Both started as the same raster file. One got traced into vectors first. Let's build that
> ourselves."

## [10 Mins] Direct Instruction

**"I Do":** using a scanned hand-drawn sketch, the teacher live-demos:

1. Placing the raster image and opening the **Image Trace panel** (Window > Image Trace).
2. Applying the **Black and White Logo** preset, adjusting **Threshold** up and down to show how
   it changes what becomes black vs. white.
3. Switching presets to **3 Colors** on a different, more colorful source image, and enabling
   **Ignore White** to drop the background.
4. Adjusting Paths, Corners, and Noise sliders to clean up stray specks and smooth jagged edges.
5. Clicking **Expand** and showing that the result is now real, selectable, editable vector
   paths — no longer a live trace linked to the original raster.

{: .highlight }
**Check for Understanding**
**Recall:** "What button turns a live Image Trace result into actual editable paths?"
**Analysis:** "Why did raising the Threshold slider turn more of the image black?"
**Synthesis:** "A client hands you their old logo as a blurry JPEG with no source file. Walk
through, in order, the steps you'd take to get them a clean, scalable vector version."

## [23 Mins] Guided Practice

{% include worksheet.html file="image-trace-reference" title="Image Trace Reference" presentation="placeholder" %}

**Pair-share (2 min):** compare with your partner which Threshold setting you're choosing on the
same source image, and why.

1. Place your assigned source image and open Image Trace.
2. Choose an appropriate preset for your image (Black and White Logo for high-contrast art, 3
   Colors or higher for a photo).
3. Adjust Threshold (if applicable) and the Paths/Corners/Noise sliders until the result is
   clean — no stray specks, no lost important detail.
4. **Expand** the result into real vector paths and confirm you can now select individual paths.
