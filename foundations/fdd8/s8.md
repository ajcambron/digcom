# S | 8 | Sticker Pack / Merch Pattern

{: .highlight }
This is Unit 8's project block — several class meetings under one brief. You'll be pulling
techniques (and possibly artwork) from 8.1–8.4 into one finished, multi-piece set.

## Project Idea

| Driving Question | How can a small, related set of graphics — stickers, or one repeating merch pattern — feel like one cohesive product instead of four unrelated pieces? |
| :--- | :--- |
| **Learning Goals** | {::nomarkdown}<ul><li>Apply a brush or a repeating pattern deliberately, not decoratively.</li><li>Reuse one symbol and one saved graphic style across multiple pieces for visual consistency.</li><li>Convert at least one raster or hand-drawn source into vector artwork using Image Trace.</li><li>Use a generative AI prompt as a starting point for at least one element, then hand-edit it.</li></ul>{:/} |
| **Project Summary** | Design a small sticker pack (4–5 related stickers) or one repeating pattern for a merch product (a T-shirt, a tote bag), combining every Unit 8 technique. |
| **Major Products** | A multi-artboard .ai file and a set of per-artboard exports. |
| **Making it Public** | Publish the exported set to your Google Sites portfolio. |
| **Key Project Documents** | [Rubric](/resources/90_rubrics) |

## [10 Mins] Bell Ringer / Hook

Today's stinger: name one sticker pack or merch design you've actually seen in real life, and one
specific thing that makes its pieces feel like a matched set rather than random clip art.

## [15 Mins] Project Brief & Demo

> "Watch how this one sticker uses a symbol I already built, a shape I traced from a photo, and
> an AI-generated starting point I hand-edited — four Unit 8 tools, one small piece of art."

**Required elements checklist** (all four required somewhere across your set):

1. **Brush or Pattern** — a brushed line or a repeating pattern fill used deliberately.
2. **Symbol + Graphic Style** — one symbol reused at least twice, sharing one saved style.
3. **Image Trace** — at least one element built by tracing a raster or hand-drawn source.
4. **Generative AI** — at least one element that started as an AI-generated prompt result, then
   was hand-edited.

## [45 Mins] Studio Time

1. Choose your format: a 4–5 piece sticker pack, or one repeating merch pattern (or both).
2. Sketch a rough layout or theme on paper before opening Illustrator.
3. Build your set in Illustrator, working through the required-elements checklist above. Reuse
   your 8.1–8.4 files as raw material or reference where it helps.
4. **Structured Peer Review (middle project day):** trade screens with a partner and run a
   Plus/Delta pass.

5. Revise based on peer feedback before your final project day.

## [30 Mins] GMetrix / BrainBuffet Self-Guided Strand

Continue any remaining **GMetrix Module 5/6** progress during earlier project days.

2. Use the **Asset Export panel** with **Use Artboards** enabled to export the whole set at once.
