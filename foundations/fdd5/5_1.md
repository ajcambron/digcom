# 5.1 | Type Anatomy & Classification

{: .vocab }
{% include vocab/fdd-type-anatomy.md %}

Welcome to Unit 5 — Typography. Before you can control type in Illustrator, you need the
vocabulary to talk precisely about what you're looking at. Today's about learning to *see* type
the way a designer does.

## Direct Instruction — Reading a Letterform (~10 min)

> "Every letter you've ever read is built on the same invisible scaffolding — a baseline it sits
> on, and a few key heights above and below it."

The teacher labels a large projected letterform live: baseline, x-height, cap height, and
descender line, then introduces the 4 broad classifications with example typefaces:

- **Serif** — small finishing strokes at the ends of letters (e.g. Times New Roman, Georgia)
- **Sans-Serif** — no finishing strokes, cleaner and more geometric (e.g. Helvetica, Arial)
- **Script** — imitates handwriting or calligraphy
- **Display** — designed for large, attention-getting use rather than long text

{: .discussion }
**Recall:** What's the difference between a serif and a sans-serif typeface? **Analysis:** Why
might a designer choose a script typeface for a wedding invitation but never for a textbook's body
copy? **Synthesis:** If you were designing a horror movie poster, which classification would you
choose for the title, and why?

## Guided Practice — Label & Classify (~23 min)

{% include worksheet.html file="fdd5-type-anatomy-notes" title="5.1 Guided Notes: Type Anatomy & Classification" presentation="placeholder" %}

1. **Label the diagram (~8 min):** using the word bank, label the 4 lines on the provided
   letterform diagram.
2. **Fill-in-the-blank vocabulary (~7 min):** complete the guided notes' definitions using today's
   vocabulary.
3. **Classify (~8 min):** in pairs, sort the provided typeface samples into serif, sans-serif,
   script, or display, and be ready to justify one choice using anatomy vocabulary (e.g. "this one
   has small serifs at the base of each stroke").

{: .highlight }
When in doubt, zoom in. Classification decisions get much easier once you can actually see whether
a stroke ends in a serif or not.
