# 5.3 | Type on a Path & Special Type

## Key Terms

{: .vocab }
{% include vocab/fdd-type-objects.md %}

So far you've typed text without thinking much about what kind of type object it actually is.
Today you'll learn the 3 fundamental types — and use the most special one, Type on a Path, to
build a circular badge design.

## Direct Instruction — Live Demo (~10 min)

> "Watch what the same word does depending on which type tool I click with first."

The teacher live-demos the same word three ways:

1. **Point type** — typed with the regular Type tool, growing endlessly to one side.
2. **Area type** — typed inside a rectangle, wrapping automatically.
3. **Type on a path** — typed along a circle, following its contour.

{: .discussion }
**Recall:** What's the key behavioral difference between point type and area type? **Analysis:**
Why would a paragraph of body copy always use area type instead of point type? **Synthesis:** If
you needed text to curve around the top of a badge logo, why wouldn't manually rotating each
letter by hand work as well as Type on a Path?

## Guided Practice — Build a Badge (~23 min)

{% include worksheet.html file="fdd5-type-on-path-guide" title="Type on a Path & Special Type" presentation="placeholder" %}

1. **Sketch (~5 min):** on the reference sheet, sketch a quick idea for a circular badge (think:
   a stamp, a logo seal, or a coffee shop badge).
2. **Build (~13 min):** draw a circle, use the **Type on a Path tool** to add your top text, and
   a second circle (or the same path) for bottom text if your design needs it.
3. **Adjust (~5 min):** use the path's start/end brackets to fine-tune where the text begins, and
   flip the orientation if it's reading upside-down.

{: .highlight }
If your text is flowing to the *inside* of the circle instead of around the outside, drag the
small vertical bracket at the path's start point across to the other side of the path.
