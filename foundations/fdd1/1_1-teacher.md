# 1.1 | Line Assignment — Teacher Plan

{% include ctelessonplan.md %}

## Source

Adapted from AIGA's *Unit 1A: Introduction to Graphic Design* (9–12 curriculum),
`1A_IntroductionToGraphicDesign.pdf` — the "An introduction to graphic design" intro section
(career list, engagement hook) and Assignment 1: Line, run at AIGA's full spec (16 thumbnails →
3 roughs → 1 comp) since our 78-minute period exceeds AIGA's own 45–60 min budget for the same
assignment.

## Timing (fills the full 78 minutes — no GMetrix all unit, see the planning doc's Class Period Structure note)

| Segment | Minutes | What happens |
|---|---|---|
| Bell Ringer | 10 | Paper stinger |
| Guided Notes: What is Design? | 12 | Direct instruction + fill-in-blank notes, whole-class |
| Line Assignment (thumbnails → roughs → comp) | 50 | Independent work, teacher circulating |
| Wrap-up / photograph | 6 | Save for reference on the S1 project day |

## The 7 — how this lesson hits each element

| Element | This lesson |
|---|---|
| Organization for Learning | Guided notes outline + the thumbnail/rough/comp worksheet sequence itself. |
| Connection to Learning | AIGA's own engagement hook — ask what students think graphic design is before defining it formally. |
| Target for Learning | SWBAT generate multiple abstract compositions using line, evaluate them, and carry the strongest through thumbnail → rough → comp to a finished, neatly-executed design. |
| Collaboration around Learning | Students may ask a neighbor for a second opinion when selecting their strongest rough, per AIGA's own suggestion. |
| Evidence of Learning | The physical thumbnails, roughs, and comp, collected as the exit ticket. |
| Summarization of Learning | Reflection on what changed between the first thumbnail and the finished comp. |
| Accommodations to the Plan | See Differentiation Matrix below. |

## Differentiation Matrix

| Cohort | Modification |
|---|---|
| IEP/504 | Reduce to 8 thumbnails instead of 16; per AIGA's own accommodation note, a student with limited motor skills may use a computer if available, thicker markers, or work with a partner. |
| ELL/Multilingual | Word bank for the guided notes blanks; bilingual glossary card for line/thumbnail/rough/comp at each table. |
| Advanced/GT | Require the comp to use at least 3 distinct line-weight variations and explain the choice in one sentence on the back. |

## AIGA note not used today

AIGA's engagement extension ("find and follow at least ten designers via Bēhance, Instagram, or
Pinterest") requires internet access and is deferred to an optional take-home once computer/
network access is reliable — not an in-class Unit 1 activity.

## Materials
- Guided notes handout (paper, one per student)
- Thumbnail sheet — 16 boxes (paper, one per student; a printed grid template works)
- Plain paper for roughs and comp
- Pencils and black markers
