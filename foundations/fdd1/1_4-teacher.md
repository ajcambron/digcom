# 1.4 | Communicating Design Plans — Teacher Plan

{% include ctelessonplan.md %}

## Timing (fills the full 78 minutes — no GMetrix, see 1.1's teacher page)

| Segment | Minutes | What happens |
|---|---|---|
| Bell Ringer | 10 | Paper stinger |
| Guided Notes | 30 | Direct instruction + fill-in-blank notes, whole-class |
| Sketch a plan | 15 | Independent work |
| Write a mini style note | 10 | Independent work |
| Pitch it (groups of 3) | 10 | Small-group, each student pitches <1 min |
| Save, submit & pack up | 3 | Collect handouts |

(Pitch timing is tight — 3 students × <1 min each + feedback ≈ 5-6 min/group; with transitions
this fits in 10, but call time firmly.)

## The 7 — how this lesson hits each element

| Element | This lesson |
|---|---|
| Organization for Learning | One-page plan template (thumbnail box + color swatch + audience line + style note) students fill in by hand. |
| Connection to Learning | Guided notes explicitly link back to 1.2's rough-sketch-for-client-approval concept and 1.3's client request, showing this lesson as the synthesis of both. |
| Target for Learning | SWBAT produce a rough design plan (sketch + color choice + audience statement + mini style guide) and orally pitch it, receiving and using feedback-loop language. |
| Collaboration around Learning | Small-group pitch-and-feedback round — the first oral communication formative in the unit. |
| Evidence of Learning | The student's own one-page plan + mini style note + the feedback they received, collected as the exit ticket. |
| Summarization of Learning | Reflection on what question a client would likely ask back, checked against what their pitch group actually asked. |
| Accommodations to the Plan | See Differentiation Matrix below. |

## Formative (paper F2, planning-lesson variant)

Per the Formative Assessment System, planning lessons use F2 on the planning artifact **with an
in-class-announced constraint**. Constraint for the plan sketch, announced verbally: *"Your color
choice has to be one you'd actually avoid if the client's audience were toddlers — write one
sentence explaining why."*

## Differentiation Matrix

| Cohort | Modification |
|---|---|
| IEP/504 | Provide a thumbnail box with a light pre-printed grid; reduce the ordering warm-up to 3 steps instead of 5; allow the pitch to be read aloud from notes rather than delivered from memory. |
| ELL/Multilingual | Word bank of the 5 process-order terms with icons; allow the audience sentence and style note to be written in a student's home language with an English gloss; pitch may be delivered with a translated script. |
| Advanced/GT | Require two feedback-loop iterations shown on the same page (an initial thumbnail and a revised one, with a one-line note on what changed and why) before the pitch round. |

## Materials
- Guided notes handout (paper, one per student)
- One-page plan template (paper, one per student)
- A timer visible to the room for the pitch round
