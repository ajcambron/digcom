# 1.4 | Communicating Design Plans — Teacher Plan

{% include ctelessonplan.md %}

## The 7 — how this lesson hits each element

| Element | This lesson |
|---|---|
| Organization for Learning | One-page plan template (thumbnail box + color swatch + audience line) students fill in by hand. |
| Connection to Learning | Warm-up ordering activity (Draft/Sketch/Final/Feedback/Revise) surfaces what students already understand about revision before naming it formally. |
| Target for Learning | SWBAT produce a rough design plan (sketch + one color choice + audience statement) that communicates intent without being a finished design. |
| Collaboration around Learning | Whole-class read of a sample style guide, discussing why it's shown *before* final work. |
| Evidence of Learning | The student's own one-page plan sketch, collected as the exit ticket. |
| Summarization of Learning | Reflection on what question a client would likely ask back. |
| Accommodations to the Plan | See Differentiation Matrix below. |

## Formative (paper F2, planning-lesson variant)

Per the Formative Assessment System, planning lessons use F2 on the planning artifact **with an
in-class-announced constraint**. Constraint for this lesson, announced verbally: *"Your color
choice has to be one you'd actually avoid if the client's audience were toddlers — write one
sentence explaining why."*

## Differentiation Matrix

| Cohort | Modification |
|---|---|
| IEP/504 | Provide a thumbnail box with a light pre-printed grid to structure the sketch; reduce the ordering warm-up to 3 steps instead of 5. |
| ELL/Multilingual | Word bank of the 5 process-order terms with icons; allow the audience sentence to be written in a student's home language with an English gloss. |
| Advanced/GT | Require two feedback-loop iterations shown on the same page (an initial thumbnail and a revised one, with a one-line note on what changed and why). |

## Materials
- Sample style guide page (printed, for guided practice)
- Process-order warm-up half-sheet
- One-page plan template (paper, one per student)
