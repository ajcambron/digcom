# 1.4 | Color Assignment — Teacher Plan

## Source

Adapted from AIGA's *Unit 1A*, Assignment 4: Color (`1A_IntroductionToGraphicDesign.pdf`), at
full AIGA spec (16 thumbnails → 3 roughs → 1 comp). Part 3's Class Closure is AIGA's own
suggested closure activity for the whole 4-assignment sequence, used here verbatim since this is
the last of the 4 element days.

## Timing (fills the full 78 minutes — no GMetrix all unit)

| Segment | Minutes | What happens |
|---|---|---|
| Bell Ringer | 10 | Paper stinger |
| Guided Notes: Communicating Design Plans | 10 | Direct instruction + fill-in-blank notes, whole-class |
| Color Assignment (thumbnails → roughs → comp) | 42 | Independent work, teacher circulating |
| Class Closure (all 4 comps together) | 10 | Whole-class, comps displayed |
| Wrap-up / photograph | 6 | Decide which of the 4 comps is strongest, for S1 |

## The 7 — how this lesson hits each element

| Element | This lesson |
|---|---|
| Organization for Learning | Guided notes outline + the thumbnail/rough/comp worksheet sequence, now familiar from 3 prior repetitions. |
| Connection to Learning | Guided notes explicitly link back to 1.1's rough-sketch-for-approval concept and 1.3's audience/goals, framing this as the synthesis lesson. |
| Target for Learning | SWBAT apply the element of color through the full thumbnail-rough-comp process, and evaluate all 4 of their element comps as a set for a unifying idea. |
| Collaboration around Learning | Whole-class Closure discussion comparing everyone's 4-comp sets. |
| Evidence of Learning | Completed guided notes + 16 thumbnails + 3 roughs + comp + the "strongest comp" decision, collected as the exit ticket. |
| Summarization of Learning | Reflection identifying and justifying their single strongest comp across the whole unit. |
| Accommodations to the Plan | See Differentiation Matrix below. |

## Turn-In Grading

Check system (see Resources > Rubrics): **✓** = guided notes complete, all 16 thumbnails
attempted, 3 roughs, a finished comp, and a strongest-comp decision with a reason. **✓+** = same,
plus the comp shows real refinement (resolved composition, deliberate use of color) beyond the
minimum. **✓−** = guided notes incomplete, thumbnail count noticeably short, comp
missing/unfinished, or no strongest-comp decision given.

## Differentiation Matrix

| Cohort | Modification |
|---|---|
| IEP/504 | Reduce to 8 thumbnails instead of 16; allow the "strongest comp" decision to be made with teacher input rather than fully independently. |
| ELL/Multilingual | Word bank for the guided notes blanks; allow the Closure discussion response to be written in a student's home language with an English gloss. |
| Advanced/GT | During Closure, require a specific plan (not just an observation) for how they'd unify all 4 comps if repeating the exercise, including one concrete change per comp. |

## Materials
- Guided notes handout (paper, one per student)
- Thumbnail sheet — 16 boxes (paper, one per student)
- Plain paper for roughs and comp
- Pencils and colored pencils
- Wall space or desk space to display all 4 comps together for Closure
