# 1.3 | Purpose, Audience & Client Goals — Teacher Plan

{% include ctelessonplan.md %}

## Timing (fills the full 78 minutes — no GMetrix, see 1.1's teacher page)

| Segment | Minutes | What happens |
|---|---|---|
| Bell Ringer | 10 | Paper stinger |
| Guided Notes | 30 | Direct instruction + fill-in-blank notes, whole-class |
| Client Request Breakdown (sample) | 20 | Independent, then whole-class compare |
| Write Your Own + partner trade | 20 | Pair work |
| Save, submit & pack up | 5 | Collect handouts |

Note the 3-part split here is a bit tighter than 1.1/1.2's two-part structure — this lesson has
more discrete steps (read a sample, write your own, trade and analyze a partner's), so budget
transitions carefully; the constraint reveal for Part 3 should be announced verbally right before
students start writing, not printed on the handout ahead of time.

## The 7 — how this lesson hits each element

| Element | This lesson |
|---|---|
| Organization for Learning | Guided notes + a labeled worksheet (Client / Audience / Goal / Accessibility fields) used for both the sample and the student's own request. |
| Connection to Learning | Discussion on spotting a design clearly not made for you, before formally defining audience/demographics. |
| Target for Learning | SWBAT identify the client, target audience, and stated goal of a design request, and name one accessibility consideration, for both a given example and one they author themselves. |
| Collaboration around Learning | Partner trade-and-breakdown activity in Part 3 — students analyze a peer's client request, not just their own. |
| Evidence of Learning | Completed guided notes + both worksheets (sample breakdown, own request + partner's breakdown), collected as the exit ticket. |
| Summarization of Learning | Reflection on what was unclear in the partner's request and what clarifying question they'd ask. |
| Accommodations to the Plan | See Differentiation Matrix below. |

## Formative (paper F2, planning-lesson variant)

Per the Formative Assessment System, planning lessons use F2 on the planning artifact **with an
in-class-announced constraint** as the AI-resistance tripwire. Constraint for Part 3, announced
verbally (not written on the handout ahead of time): *"Your client request must include one
detail that seems to contradict the stated audience — your partner has to catch it."*

## Differentiation Matrix

| Cohort | Modification |
|---|---|
| IEP/504 | Provide a fill-in-the-blank template for the client request ("My client is ______, who needs ______ for ______.") instead of open composition. |
| ELL/Multilingual | Sentence frames for each worksheet field; allow the client request to be written in a student's home language with an English glossary of the 4 key terms. |
| Advanced/GT | Require two accessibility considerations instead of one, including at least one beyond vision/hearing (e.g., cognitive load, motor access). |

## Materials
- Guided notes handout (paper, one per student)
- Sample client request handout
- Client Request worksheet (paper, one per student, used for both authoring and partner breakdown)
