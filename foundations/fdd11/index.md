# Unit 11 | Page Layout, Packaging & Promotional Design

Unit 11 is the first of FDD's two **Extra Units** (May 4 – Jun 4, 2027) — post-certification
enrichment content that isn't on the Illustrator ACP exam, taught after Unit 10's certification
window closes. It builds toward two connected real-world design skills: laying out a multi-page
publication (culminating in an actual yearbook spread), and designing packaging/promotional
pieces for a brand. Both use Illustrator skills already built across Units 1–9 — nothing here is
a new tool the students haven't touched, it's a new *application* of tools they already know.

{: .highlight }
Nothing in this unit is ACP-tested — see each lesson's `standard:` field, which reads "Not
ACP-tested — post-certification enrichment" instead of an ACP objective tag. The unit still
carries full compliance rigor (78-minute timing, The 7, a real Differentiation Matrix, real
Turn-In criteria) — the students are still in the room, even though the exam is behind them.

## Lessons
- [11.1 – Page Layout Fundamentals](11_1.md) — margins, gutters, columns, hierarchy, alignment
- [11.2 – Working with Grids & Multi-Page Documents](11_2.md) — multi-artboard documents as a
  lightweight page-layout tool
- [11.3 – Packaging & Promotional Design Concepts](11_3.md) — dielines, brand identity, promotional
  collateral
- [11.4 – Building the Yearbook Spread](11_4.md) — applying 11.1–11.3's skills to a real two-page
  spread
- [S11 – Brand Package: Promotional Spread + Product Mockup](s11.md) — summative capstone

## Source

`_planning/2026-27-scope-and-sequence.md`'s "FDD Extra Units" section gives only a rough bullet
list to build from — a Yearbook Spread page-layout project, and packaging/promotional design /
branding campaign work (FDD outcome 3–4) — with no per-lesson table like every other unit. The
breakdown above is this unit's own first-pass answer to that gap.

**Rationale for the 4+1 split:** page layout is the throughline that makes the yearbook spread
possible, so it comes first (11.1) and gets its own dedicated tool lesson before students touch
Illustrator's multi-artboard workflow (11.2). Packaging/promotional concepts (11.3) is placed
third rather than earlier because it's genuinely a distinct skill (dielines and brand systems,
not page grids) — it's also where each student picks the brand they'll design for through the
rest of the unit. 11.4 then applies the page-layout skills from 11.1–11.2 to build a real,
graded artifact (the yearbook spread itself) and deliberately serves as the unit's
"pre-summative" lesson, using an F4 Fix-This-File formative (a broken practice layout to repair)
as the natural review checkpoint the day before independent project time opens. By S11, students
are carrying forward both halves of the unit — the page-layout skills from 11.1/11.2/11.4 and
the brand concept from 11.3 — into a summative that asks for both a promotional piece and a
packaging mockup for the same brand, specifically so it can't be completed from only one half of
the unit.

## ACP Alignment

None — this is post-certification enrichment content, not on the Adobe Certified Professional
Graphic Design & Illustration exam. See the Foundations course's general Learning Outcomes
(`foundations/index.md`, outcomes 3–4: packaging/promotional/branding design, and page-design
structure) for the standards this unit still serves.

## Assessment Rhythm

Each formative lesson (11.1–11.4) carries its own lesson-level formative (F1–F4, chosen by lesson
type — see each lesson's Notes field for which one and why) and cycles through the Exit Ticket
Bank in the standard order (Stoplight → Glow & Grow → Emoji Meter → 3-2-1). On the S11 project
day, students also complete a cumulative vocabulary quiz covering this unit's terms and receive a
grade compiled from the unit's daily bellringers, same as every other unit.
