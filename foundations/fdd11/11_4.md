# 11.4 | Building the Yearbook Spread

## Key Terms

{: .vocab }
{% include vocab/fdd-page-layout.md %}

{: .vocab }
{% include vocab/fdd-grids-multipage.md %}

A **spread** is two facing pages designed to be read as one visual unit — exactly what a
yearbook's two-artboard layout looks like in Illustrator. Today you'll fix a broken practice
spread, then build a real one of your own.

## Bell Ringer (~10 min)

Open the provided Fix-This-File practice spread. Before touching anything, list every problem you
can spot — inconsistent margins, a misaligned grid, text that all looks the same size (no
hierarchy), a missing or wrong folio.

## Direct Instruction (~10 min)

Watch your teacher fix one of the practice file's planted errors live, narrating the diagnosis
out loud. Then: a real yearbook spread needs a **headline**, a **byline** (who wrote/shot it), a
grid of 3–4 photo placeholders, a **caption** for each photo, and a consistent **folio**.

{: .discussion }
Why does a yearbook spread need a caption on every photo, even when the photo seems
self-explanatory?

## Guided Practice (~23 min)

With a partner, finish fixing every remaining error in the practice file. Check each fix against
the vocab bank above before moving on — a "fix" that doesn't actually restore consistency doesn't
count.

## Studio/Project Work Time (~30 min)

Now build your own **two-page yearbook spread**, using two artboards side by side:

1. Set up a consistent grid and margins across both artboards (from 11.2).
2. Add a headline and byline.
3. Build a grid of 3–4 photo placeholders with a caption under each.
4. Add a consistent folio to both pages.

{: .reflection }
Which planted error in the practice file was the easiest to spot, and which took the longest to
find?

## Exit Ticket / Wrap-Up (~5 min)

Save your file, then take a screenshot showing your corrected practice file and your own
in-progress spread.
