# S | 6 | Portfolio Polish Project

This is a different kind of summative. Instead of starting something new, you're going to make
something you already made **better** — using everything you've learned in Unit 6 about getting a
piece truly ready for output.

## Project Idea

| Driving Question | What does it actually take to turn a finished-looking piece into one that's genuinely ready for its real destination? |
| :--- | :--- |
| **Learning Goals** | Diagnose and correct a color mode mismatch; refine text using paragraph/area type tools; apply a transformation purposefully; re-export or save a file in the correct format for its destination. |
| **Project Summary** | Students select one piece from their own earlier FDD portfolio and revise it against a required checklist: color mode, text refinement, a transformation, and correct file output. |
| **Major Products** | A revised file, submitted alongside the original for direct comparison. |
| **Making it Public** | The revised piece replaces (or is added alongside) the original on each student's portfolio website. |
| **Key Project Documents** | Portfolio Polish Revision Checklist (below) |

## Select & Diagnose (~15 min)

1. **Choose one piece** from your portfolio — anything from Unit 1 through Unit 5.
2. **Diagnose it honestly** against the checklist below. Most pieces have at least one real issue:
   a color mode that doesn't match its intended output, text that was never properly refined, or
   an export format that doesn't fit where the piece is actually headed.

{% include worksheet.html file="fdd6-portfolio-polish-checklist" title="Portfolio Polish Revision Checklist" presentation="placeholder" %}

## Revise (~45 min)

Work through all 4 required revisions, documenting exactly what you changed for each on your
checklist:

1. **Color mode** — correct it for the piece's actual intended output (e.g. switch a
   web-only RGB piece intended for print to CMYK, or fix an out-of-gamut color).
2. **Text refinement** — apply paragraph/area type tools (alignment, indents, spacing,
   hyphenation) to any text in the piece.
3. **Transformation** — apply at least one transformation (scale, rotate, reflect, shear, or
   Live Corners) purposefully, not just accidentally.
4. **Re-export/save** — save or export the finished revision in the file format that's actually
   correct for its destination.

{: .highlight }
This is a revision, not a redo. The goal is a measurably better version of a piece you already
made — not starting over from scratch.
