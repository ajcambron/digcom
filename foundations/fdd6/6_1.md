# 6.1 | Saving & File Formats

## Key Terms

{: .vocab }
{% include vocab/fdd-file-types.md %}

Welcome to Unit 6 — Refinement & Output Prep. Every skill in this unit is about the last mile: making
sure a finished piece is actually correct for wherever it's headed next. Today's question: **which
file format do you actually need?**

## Direct Instruction — Live Export Comparison (~10 min)

> "Watch what happens to this same logo when I export it 4 different ways — same artwork, 4 very
> different files."

The teacher live-exports one piece of artwork as .pdf, .svg, .png, and .jpg, comparing file size,
whether transparency survived, and whether the result is still editable.

{: .discussion }
**Recall:** What's the difference between a vector format and a raster format? **Analysis:** Why
would a .jpg be a poor choice for a logo that needs a transparent background? **Synthesis:** If a
print shop asked for a "universally viewable proof that still preserves editing," which format
would you send, and why?

## Guided Practice — Match & Export (~23 min)

{% include worksheet.html file="fdd6-file-formats-reference" title="File Formats Quick Reference" presentation="placeholder" %}

1. **Match (~8 min):** your teacher will describe 3 delivery scenarios. Write the correct file
   format for each on your reference sheet.
2. **Export (~15 min):** open the provided artwork file and export it correctly for **2 different
   destinations** (e.g. a transparent PNG for a website, and a print-ready PDF for a client).

{: .highlight }
Always keep your original **.ai** file, no matter what you export. It's the only format that keeps
everything fully editable for next time.

## Exit Ticket / Wrap-Up (~5 min)

Screenshot both of your exported files side by side.
