# 6.4 | Transformations & Live Corners

{: .vocab }
{% include vocab/fdd-transformations.md %}

Last lesson before S6. Today covers the transformation tools you'll use constantly when
finalizing any piece — resizing, rotating, flipping, slanting, and rounding corners.

## Direct Instruction — Live Demo (~10 min)

> "Watch what changes when I rotate this same shape around its center versus around one corner —
> same angle, completely different result."

The teacher live-demos on a sample shape:

1. **Scale** — proportional (Shift-drag) vs. non-proportional resizing.
2. **Rotate** — around the default center vs. a custom reference point.
3. **Reflect** — flipping across a vertical axis.
4. **Shear** — slanting while keeping sides parallel.
5. **Live Corners widget** — dragging a rectangle's corner handle to round it live.

{: .discussion }
**Recall:** What's the difference between scale and shear? **Analysis:** Why does choosing a
different reference point change the result of a rotation, even at the exact same angle?
**Synthesis:** If you needed to rotate one shape around a specific corner of another shape (not
its own center), how would you set that up?

## Guided Practice — Practice Checklist (~23 min)

{% include worksheet.html file="fdd6-transformations-reference" title="Transformations Quick Reference" presentation="placeholder" %}

1. **Proportional scale (~6 min):** scale one object larger while holding Shift.
2. **Custom-point rotation (~9 min):** click to set a custom reference point away from the
   object's center, then rotate around it.
3. **Live Corners (~8 min):** draw a rectangle and drag its Live Corners widget to round the
   corners without switching tools.

{: .highlight }
Forgetting Shift while scaling is the single most common way a logo ends up accidentally
stretched. Make it a habit.
