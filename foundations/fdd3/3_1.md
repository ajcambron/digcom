# 3.1 | Color Theory

## Key Terms

{: .vocab }
{% include vocab/fdd-color-theory.md %}

Every project you've built so far has used whatever color you happened to click. Starting today,
color becomes a deliberate decision.

## Direct Instruction (~10 min)

{% include worksheet.html file="guided-notes-3-1" title="3.1 Guided Notes: Color Theory" presentation="placeholder" %}

Every color can be described by three properties: **hue** (which color — red, blue, yellow-green),
**saturation** (how intense or dull), and **value** (how light or dark). Arranging hues around a
**color wheel** reveals useful relationships: colors directly across from each other
(**complementary**) create high contrast and energy; colors next to each other
(**analogous**) feel harmonious and calm; a single hue at different values (**monochromatic**)
feels unified and simple.

Then the practical side: Illustrator lets you dial in any color three ways — **CMYK** (for
print), **RGB** (for screens), or **HSB** (often the most intuitive way for a human to reason
about a color). A **hex value** is just another way of writing an RGB color, used constantly on
the web. **Grayscale** strips out hue and saturation entirely. A **spot color** is a single,
exact pre-mixed ink instead of a CMYK build, and a **rich black** deepens a large solid black area
beyond what pure K alone can do.

> "If a client says 'make it feel calm,' that's a color theory decision before it's a software
> decision — you'd reach for an analogous scheme or a monochromatic one, not a jarring
> complementary pair."

**Scaffolded questions — cold-call through all three:**

> **Recall:** "What are hue, saturation, and value, in your own words?"

> **Analysis:** "Why might a complementary color scheme work well for a warning label, but poorly
> for a spa's logo?"

> **Synthesis/Extension:** "If you had to design a color scheme that felt 'energetic but
> trustworthy' at the same time, what relationship(s) might you combine, and why?"

## Guided Practice (~23 min)

1. **Open the Color panel** (Window > Color) and mix a color you like using CMYK sliders.
2. **Switch the panel's mode** to RGB, then to HSB, and screenshot all three views of the same
   color — notice the numbers change but the color itself doesn't.
3. **Pick a color scheme** (complementary, analogous, or monochromatic) and build a small set of
   4–5 filled shapes demonstrating it — don't label which scheme it is yet.
4. **Turn and Talk:** trade screens with a partner. Can they correctly guess which scheme you
   built before you tell them?

{: .discussion }
Which felt easier to reason about while you were picking colors — CMYK numbers, RGB numbers, or
HSB? Why do you think that is?
