# 3.3 | Swatches & Gradients

## Key Terms

{: .vocab }
{% include vocab/fdd-swatches-gradients.md %}

Time to apply real, reusable color to the icon you built in 3.2.

## Direct Instruction (~10 min)

{% include worksheet.html file="guided-notes-3-3" title="3.3 Guided Notes: Swatches & Gradients" presentation="placeholder" %}

A **process color** is the everyday saved swatch, built from CMYK or RGB percentages. A **spot
swatch** represents a single pre-mixed ink — the same idea as 3.1's spot color, now as an actual
panel item. A **global swatch** is the powerful one: edit it once, and every object using it
updates automatically everywhere in the file.

> "Imagine a client's exact brand blue is used on 40 different shapes across a poster. If it's a
> global swatch and they change their mind about the shade, you edit it once. If it's not, you're
> hunting down 40 shapes by hand."

The **Color Guide panel** takes one base color and instantly suggests whole harmonious groups —
the same complementary/analogous/monochromatic relationships from 3.1, generated for you. Then
**gradients**: a **linear** gradient blends along a straight line, a **radial** blends outward
from a center point, and each **color stop** along the ramp can be repositioned, recolored, or
faded via opacity.

**Scaffolded questions — cold-call through all three:**

> **Recall:** "What's the difference between a process swatch and a global swatch?"

> **Analysis:** "Why does a global swatch matter more on a real client project with dozens of
> shapes than on a single one-off icon?"

> **Synthesis/Extension:** "If a client's brand had 3 official colors, how would you set up your
> Swatches panel so nobody on the design team ever mixes color by eye again?"

## Guided Practice (~23 min)

1. **Open your icon file from 3.2.**
2. **Save at least one of its colors as a global swatch** (Swatches panel menu > New Swatch >
   check "Global"), and apply it to 2+ shapes.
3. **Test it:** double-click the global swatch and change its hue — confirm both shapes update
   automatically. Screenshot before and after.
4. **Open the Color Guide panel**, click your base color, and browse the harmony groups it
   suggests — compare to the scheme you named in 3.1.
5. **Add a gradient** to one shape: try linear first, then radial. Edit at least 3 color stops
   (reposition, recolor, or adjust opacity on each).
6. **Turn and Talk:** compare your Color Guide's suggested harmonies with a partner's — do you get
   different groups from different base colors?

Would you rather discover a color needs to change before or after you've applied it to 40 shapes
by hand instead of as a global swatch?
