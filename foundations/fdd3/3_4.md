# 3.4 | Align, Distribute & Arrange

## Key Terms

{: .vocab }
{% include vocab/fdd-align-distribute.md %}

Colorful shapes (3.3) aren't a composition yet — today's about precisely arranging them.

## Direct Instruction (~10 min)

{% include worksheet.html file="guided-notes-3-4" title="3.4 Guided Notes: Align, Distribute & Arrange" presentation="placeholder" %}

The **Align panel** lines objects up — to each other, to the artboard, or to a **Key Object**
(click any selected object a second time to designate it as the anchor everything else aligns
against). **Distribute** goes a step further, spacing a whole set evenly instead of just sharing
one edge.

> "Align gets things on the same line. Distribute makes sure the *gaps* between them are actually
> equal — those are two different problems, and eyeballing rarely solves either one."

Objects also stack in **stacking order** — the order they were drawn, front to back — changeable
with **Object > Arrange** (Bring to Front, Bring Forward, Send Backward, Send to Back). Once a
composition is finished, **Group** (Cmd/Ctrl+G) locks the pieces together so they move as one.

**Scaffolded questions — cold-call through all three:**

> **Recall:** "What's the difference between Align and Distribute?"

> **Analysis:** "Why would you want to set a Key Object instead of just using 'align to
> selection' by default?"

> **Synthesis/Extension:** "If you had 5 overlapping shapes and needed exactly one specific
> stacking order, how many Arrange commands might you need, and could you get there faster with
> fewer clicks?"

## Guided Practice — Fix-This-File (~23 min)

1. **Trade starter files with a partner.** Each scene has 5–6 overlapping shapes, scattered with
   no alignment and a stacking order that hides the wrong pieces.
2. **Screenshot the "before" state.**
3. **Set a Key Object**, then use Align + Distribute to bring the scene into an even, deliberate
   layout.
4. **Use Object > Arrange** to fix the stacking order so the intended shapes are on top.
5. **Group the finished composition.**
6. **Screenshot the "after" state** and write one sentence naming which single command (Align,
   Distribute, or Arrange) solved the biggest problem in the file.
7. **Explain to your partner** what you changed and why.

{: .discussion }
**Turn and Talk:** could you tell, just by looking at the "before" file, which single command
would fix the most obvious problem first?
