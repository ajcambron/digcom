# Unit 3 | Shape & Color

Unit 3 builds directly on Unit 2's workspace fluency, adding color theory (hue, saturation,
value, color schemes, and Illustrator's CMYK/RGB/HSB color modes), a deeper pass on shape tools
(Live Shapes, keyboard modifiers, exact dimensions), Illustrator's swatch and gradient systems,
and precise composition with Align/Distribute/Arrange. On the project day, you'll combine all
four into a Vector Self-Portrait built entirely from shape primitives — no Pen tool yet, that's
Unit 4.

## Lessons
- [3.1 – Color Theory](3_1.md) — hue/saturation/value, color schemes, CMYK/RGB/HSB
- [3.2 – Shape Tools](3_2.md) — Live Shapes, Polygon/Star, keyboard modifiers
- [3.3 – Swatches & Gradients](3_3.md) — process/spot/global swatches, Color Guide, gradients
- [3.4 – Align, Distribute & Arrange](3_4.md) — Align panel, Key Object, stacking order, Group
- [S3 – Vector Self-Portrait](s3.md) — summative project

## Source
3.1 and S3 adapt real prior FDD content (the former `fdd4/1_1.md` and `fdd4/s4.md`, written before
the 2026–27 restructure moved this unit's number); 3.2–3.4 are new lessons written directly from
Adobe Illustrator's actual shape, color, and arrangement tools. See each lesson's own `source`
field for specifics.

## ACP Alignment

objective 3.3), objective domain 4 (Objects, Paths & Text, objective 4.1.c), and objective domain

## Assessment Rhythm
Each lesson (3.1–3.4) carries its own formative — a Screenshot Receipt, a Two-Minute Drill, or an
equivalent artifact-based check tied to that day's tool. On the S | 3 project day, students also
complete a cumulative vocabulary quiz covering this unit's terms and receive a grade compiled from
the unit's daily bellringers.
