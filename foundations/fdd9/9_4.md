# 9.4 | Exporting for Screen & Print

## Key Terms

{: .vocab }
{% include vocab/fdd-export-assets.md %}

> The exact same artwork needs a different export for a website than it does for a print shop —
> get the color mode, format, or resolution wrong, and the file that looked perfect on your
> screen prints muddy or displays with a giant white box where transparency should be.

Every project you've built all year eventually needs to leave Illustrator. Today's the lesson on
doing that correctly, for two very different destinations: a screen, and a printing press.

## [10 Mins] Bell Ringer / Hook

{: .discussion }
A design looks perfect on your monitor, but the printed version comes back looking dull and
slightly wrong-colored. What's the most likely cause?

> "Probably a color mode mismatch — RGB was built for screens, CMYK for ink. Today's about
> matching your export settings to where the file is actually going."

## [10 Mins] Direct Instruction

**"I Do":** using a multi-artboard practice file, the teacher live-demos:

1. Opening the **Asset Export panel**, dragging in several artboards, and batch-exporting them
   all at once as PNGs with **Use Artboards** enabled — one file per artboard, automatically
   named.
2. Comparing that to exporting the same set as **SVG** for a responsive website use case.
3. Switching to a print-bound export: File > Export > Export As, choosing **PDF**, confirming the
   document's color mode is CMYK (not RGB) and resolution is at least 300 ppi for any raster
   content.
4. Naming the tell-tale symptoms of a mismatched export: RGB colors shifting when printed, low
   resolution artwork looking blurry at full size, missing transparency support flattening
   incorrectly.

{: .highlight }
**Check for Understanding**
**Recall:** "What export option lets you export every artboard as its own file in one click?"
**Analysis:** "Why does an RGB export look fine on screen but potentially wrong when printed?"
**Synthesis:** "Your S9 client brand project needs a website logo and a printed business card
from the same artwork. What's different about how you'd export each one?"

## [23 Mins] Guided Practice

{% include worksheet.html file="export-reference" title="Export Reference" presentation="placeholder" %}

1. Open the provided multi-artboard practice file.
2. Use the **Asset Export panel** with **Use Artboards** to batch-export the whole set as PNGs
   for screen use.
3. Export the same file as a print-ready **PDF**, confirming CMYK color mode and adequate
   resolution.
4. **Partner review:** trade exported files with a partner and check for any wrong-output
   symptoms in each other's files.
5. Write one sentence justifying your format/color mode/resolution choice for each destination.
