# 9.2 | Managing & Packaging the Client Project

## Key Terms

{: .vocab }
{% include vocab/fdd-project-packaging.md %}

> A finished design isn't actually finished until the client can open it, on their own computer,
> with nothing missing. That's what packaging is for.

Back in Unit 1 you learned to plan around a client's goals. Today is the other end of that same
relationship: how do you hand off a finished file so it actually works when it leaves your
computer?

## [10 Mins] Bell Ringer / Hook

{: .discussion }
You email a client your finished .ai file. They open it and every font looks wrong, and a photo
you placed is missing entirely. What went wrong?

> "Nothing broke — the file just wasn't packaged. Today's lesson fixes that, permanently."

## [10 Mins] Direct Instruction

**"I Do":** using a practice document with one linked image and one non-standard font, the
teacher live-demos:

1. Running **File > Package**, choosing a destination folder, and reviewing the options (copy
   linked files, collect fonts, create report).
2. Opening the resulting folder structure — Links, Fonts, and the document itself — and the
   summary report Illustrator generates automatically.
3. Reading the report to find a **flagged restricted font** and discussing what that means: the
   font's license doesn't allow its files to be redistributed with the client, so the report
   marks it separately from fonts safely included.
4. Reviewing a hypothetical client photo scenario and discussing when a **model or location
   release** would be required before delivery — not just before shooting.

{: .highlight }
**Check for Understanding**
**Recall:** "What menu command builds a complete delivery folder in one step?"
**Analysis:** "Why does Illustrator flag some fonts as restricted instead of just including every
font automatically?"
**Synthesis:** "You're delivering a flyer that uses a photo of a real person taken in a client's
private office. What two things does this lesson say you need on file before you ship it?"

## [23 Mins] Guided Practice

{% include worksheet.html file="project-packaging-checklist" title="Project Packaging Checklist" presentation="placeholder" %}

1. Open the provided practice file and run **File > Package**.
2. Open the resulting folder and the summary report; confirm the linked image copied correctly.
3. Find and record any restricted font flagged in the report.
4. **Partner audit:** trade with a partner and check each other's package folder — did they catch
   the same restricted font?
5. Write one sentence on what you'd tell the client about any font substitution needed.
