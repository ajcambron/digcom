# 9.3 | Placing & Linking Assets

## Key Terms

{: .vocab }
{% include vocab/fdd-placing-linking.md %}

> Linking keeps your file small and editable at the source — until someone moves the original.
> Embedding never breaks — but it never shrinks your file, either. Today's lesson is choosing on
> purpose, not by accident.

You just learned why File > Package copies linked files into a Links folder. Today explains
exactly what "linked" means, what breaks it, and how to fix it — plus the alternative, embedding.

## [10 Mins] Bell Ringer / Hook

{: .discussion }
You open a project file and every placed photo shows up as a gray box with a question mark. What
do you think happened?

> "That's a broken link — the placed image's source file moved, was renamed, or got deleted.
> Today we learn to prevent it, diagnose it, and fix it."

## [10 Mins] Direct Instruction

**"I Do":** the teacher live-demos:

1. Placing the same image twice — once as **Linked**, once as **Embedded** — and comparing file
   size and the Links panel entry for each.
2. Moving the linked image's source file to a different folder on purpose, then reopening the
   document to show the resulting **missing link** warning.
3. Using the **Links panel** and **Relink** to point the document back at the moved file.
4. Selecting a placed image and choosing **Edit Original** to open it in a raster editor, making
   a small change, saving, and showing the placed image update automatically in Illustrator.

{: .highlight }
**Check for Understanding**
**Recall:** "What panel shows you whether a placed image is linked or embedded, and whether a
link is broken?"
**Analysis:** "Why did embedding the image never break, even after I moved the original file?"
**Synthesis:** "You're handing off a project folder to a client who might want to update photos
themselves later. Would you link or embed those photos, and why?"

## [23 Mins] Guided Practice

{% include worksheet.html file="placing-linking-reference" title="Placing & Linking Reference" presentation="placeholder" %}

1. Place one image as linked and one as embedded in your practice file; note the file size
   difference.
2. **Partner swap:** trade practice folders with a partner after they've moved or renamed one
   linked file on purpose.
3. Diagnose the resulting broken link using the Links panel and repair it with **Relink**.
4. Use **Edit Original** on one placed image to make and save a real edit, then confirm it
   updated inside Illustrator.
