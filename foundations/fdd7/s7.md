# S | 7 | Album Cover / Gig Poster

{: .highlight }
This is Unit 7's project block — several class meetings under one brief. Bring everything you
built in 7.1–7.4; you'll be pulling techniques (and possibly artwork) from all four into one
finished piece.

## Project Idea

| Driving Question | How can a designer use layers, appearance, effects, and masking together — not as separate tricks, but as one coherent visual system — to make a single image feel intentional? |
| :--- | :--- |
| **Learning Goals** | {::nomarkdown}<ul><li>Organize a complex file using named layers and sublayers.</li><li>Build a multi-attribute Appearance stack on at least one object.</li><li>Apply at least one non-destructive Effect (shadow, glow, or 3D) deliberately, not decoratively.</li><li>Use a blending mode and either a clipping mask or an opacity mask to integrate elements with a background.</li></ul>{:/} |
| **Project Summary** | Design an album cover or gig poster (your choice) for a real or invented artist/band, combining every Unit 7 technique into one finished composition. |
| **Major Products** | A finished, layered .ai file and a flattened export suitable for print or web. |
| **Making it Public** | Publish the flattened export to your Google Sites portfolio. |
| **Key Project Documents** | [Rubric](/resources/90_rubrics) |

## [10 Mins] Bell Ringer / Hook

Today's stinger: name one album cover or gig poster you actually remember, and one specific
visual choice (not just "it looks cool") that makes it memorable.

## [15 Mins] Project Brief & Demo

> "Here's a sample cover I built using one mask, one blending mode, and one effect — I'm going to
> walk through exactly which panel did what, so you can see all four units' worth of tools
> working together instead of in isolation."

**Required techniques checklist** (all four required somewhere in your final piece):

1. **Layers** — a named, organized Layers panel (no default "Layer 1/2/3" names).
2. **Appearance** — at least one object with a multi-attribute fill/stroke stack.
3. **Effects** — at least one Effect (Drop Shadow, Glow, Feather, or 3D and Materials).
4. **Masking/Blending** — at least one blending mode plus one clipping mask or opacity mask.

## [45 Mins] Studio Time

1. Choose an artist/band (real or invented) and a genre — this drives your visual direction.
2. Sketch a rough layout on paper before opening Illustrator: where's the title, where's the
   focal image, where's any secondary text?
3. Build your composition in Illustrator, working through the required-techniques checklist
   above. Use your 7.1–7.4 files as raw material or reference where it helps.
4. **Structured Peer Review (middle project day):** trade screens with a partner and run a
   Plus/Delta pass.

5. Revise based on peer feedback before your final project day.
