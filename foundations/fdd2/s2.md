# S | 2 | Artboard Sampler

You've spent this unit learning to navigate, build, and precisely set up an Illustrator document.
Today, you'll put all four Unit 2 skills together in one project: a single document with **4
artboards**, each showing a different shape composition, built with real precision using rulers,
guides, and grids.

## Project Briefing (~10 min)

{% include worksheet.html file="artboard-planning-sheet" title="Artboard Sampler Planning Sheet" presentation="placeholder" %}

Watch the teacher set up one sample artboard from scratch: New Document with bleed → rename the
artboard → drag out guides → place shapes precisely against those guides → switch to Outline
view briefly to double-check nothing is hidden.

## Project Work Time (~23 min)

1. **Sketch your plan** for all 4 artboards on your planning sheet before opening Illustrator —
   vary the *arrangement* of shapes on each, not just the colors.
2. **File > New:** a Print document with **4 artboards**, bleed set, CMYK color.
3. **Rename every artboard** to something descriptive (not "Artboard 1/2/3/4").
4. **Build each composition** using only the basic shape/fill tools from S1 (Rectangle, Ellipse,
   Line Segment, fill color, Selection tool) — no Pen tool yet, that's Unit 4.
5. **Use at least one design aid per artboard:** rulers, a guide, the grid, or Smart Guides — vary
   which one you lean on across the 4 artboards.
6. **Halfway check-in:** trade screens with a partner and verify each other's artboard count,
   names, and bleed setting.
7. **Switch to Outline view briefly** on at least one artboard to confirm nothing is accidentally
   hidden behind something else.

{: .discussion }
Which of your 4 artboards took the most deliberate use of a design aid to get right, and which
one could you have built just as easily by eye?

## GMetrix/BrainBuffet (~30 min)

Finish **Module 1: Getting Started**, including its module-completion checkpoint — this is due
today, entered in the gradebook alongside this project.

## Save, Export & Submit (~5 min)

2. **File > Export > Export As**, choose PDF, and confirm "All" artboards are included so every
   composition exports as one multi-page PDF.
