## Direct Instruction (~15 min)

{% include worksheet.html file="guided-notes-2-3-interface" title="2.3 Guided Notes: The Illustrator Interface" presentation="/assets/presentations/fdd2-3.html" %}

Live in Illustrator, the teacher will point out each major zone in order: the **Application Bar**
at the very top, the **Control Panel** just below it (context-sensitive—it changes depending on
what's selected), the **Toolbar** running down the side, **Panels** docked to the right (Layers,
Swatches, Color, and more), and the **Document Window** in the center, showing your artboard
sitting inside the larger gray **Pasteboard**.

> "Watch what happens to the Control Panel when I select the Type tool versus when I select this
> rectangle. Same panel, completely different options, because it's context-sensitive."

{% include worksheet.html file="guided-notes-2-3-documents" title="2.3 Guided Notes: Documents & Artboards" %}

Click **File > New** to open the New Document dialog. Walk through its major fields together: a
preset category (Print, Web, Mobile, Film & Video, and more), width/height and units, orientation, color
mode (CMYK for print, RGB for anything screen-based), and, for print documents, a **Bleed**
value.

> "Notice this document can hold more than one artboard. If I'm designing a business card, I want
> the front and the back living in the same file, as two separate artboards, not two separate
> files."

**Scaffolded questions. Cold-call through all three:**

> **Recall:** "What's the difference between the Toolbar and a Panel? And separately, what's the
> difference between an artboard and the pasteboard?"

> **Analysis:** "Why does a print document need bleed, but a document meant only for a website
> never does?"

> **Synthesis/Extension:** "If you were printing a foldable brochure with 3 panels, how many
> artboards would make the most sense, and why?"

## Guided Practice | Build a Multi-Artboard Document (~26 min)

1. **File > New:** create a Print document, Letter-adjusted to a business-card size (3.5" × 2"),
 CMYK color, with **3 artboards** and **0.125" bleed** set in the dialog before clicking Create.
2. **Rename each artboard** using the Artboards panel (double-click a name to edit): call them
 "Front," "Back," and "Alt Version" instead of leaving the defaults.
3. **Turn on View > Show Bleed** (if not already visible) and draw one shape on the "Front"
 artboard that intentionally extends past the trim edge into the bleed area.
4. **Point to each interface zone as you use it:** name the Toolbar, the Control Panel, and the
 Panels dock out loud as you reach for each one.
5. **Check with a partner:** confirm each other's artboard names and bleed setting before moving
 on.
6. Save your file as `LastName_FirstName_2_3_Artboards.ai`.

{: .discussion }
If you forgot to set bleed when creating the document, is it too late to add it? (Hint: check
File > Document Setup.)
