# Unit 2 | Vector Documents & Workspace

Unit 2 is students' first formal look at Adobe Illustrator: why the program is built around
vector paths instead of pixels, how its interface is organized, how to set up a real print
document with multiple artboards, and the rulers/guides/grids/view tools that make precise work
possible. On the project day, you'll combine every one of those skills into a single
multi-artboard file — the Artboard Sampler.

## Lessons
- [2.1 – Pixels vs. Paths](2_1.md) — raster vs. vector, rasterizing, resizing
- [2.2 – The Illustrator Interface](2_2.md) — application bar, panels, toolbar, control panel
- [2.3 – Documents & Artboards](2_3.md) — New Document dialog, artboards, bleed/trim/live area
- [2.4 – Design Aids: Rulers, Guides, Grids & Views](2_4.md) — Smart Guides, Outline/Pixel
  Preview/Presentation Mode
- [S2 – Artboard Sampler](s2.md) — summative project

## Source
New unit — written directly from Adobe Illustrator's actual interface, document, and workspace
tools; no prior FDD unit covered this material.

## ACP Alignment
Objective domain 2 (Document Management, objectives 2.1–2.2) and objective domain 3 (Workflow &
Interface, objectives 3.1–3.2) — see `_planning/2026-27-scope-and-sequence.md` for the full ACP

## Assessment Rhythm
Each lesson (2.1–2.4) carries its own formative — a Screenshot Receipt, a Fix-This-File, or an
equivalent artifact-based check tied to that day's tool. On the S | 2 project day, students also
complete a cumulative vocabulary quiz covering this unit's terms and receive a grade compiled from
the unit's daily bellringers.
