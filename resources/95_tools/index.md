# Tools

Standalone tools built for this course. These live outside the main site (each is a separate
Claude Artifact), so they open in a new tab.

| Tool | What it does |
| :--- | :--- |
| [Vocabulary Worksheet Generator](https://claude.ai/code/artifact/a8967024-3e8c-48a2-bce1-68d0584a30d9){:target="_blank"} | Takes a vocabulary CSV (the same two-column Term/Definition format the "Download Vocabulary (CSV)" button produces on any lesson page) and generates a printable word-bank worksheet. |
