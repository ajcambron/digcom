# Formative Check-offs — Teacher Reference

{% include formativerubric.md %}

## Gradebook translation

| Mark | % |
| :--- | :--- |
| ✓+ | 100% |
| ✓ | 90% |
| ✓− | 75% |
| Not submitted | 0% |

**District policy — do not put this on student-facing pages:** any formative that receives an
actual submission, however weak, is floored at a minimum of 50% — a ✓− that would otherwise
translate below 50% still gets entered as 50%. This floor applies only when something was
turned in; a genuinely missing/not-submitted formative stays at 0%.

## Scope

Applies to every non-machine-graded formative: exit tickets (all four in the bank — Stoplight,
Glow & Grow, Emoji Meter, 3-2-1), Turn-In artifacts (thumbnails, roughs, comps, guided notes,
and equivalents in other courses), and any other daily classwork graded by the teacher rather
than auto-graded. Does **not** apply to auto-graded Schoology quizzes (e.g. the F5 Cumulative
Vocab Quiz) or summative projects, which keep their own point-based rubrics (see Individual
Projects / Group Projects on the public Rubrics page).

This replaces the earlier 0–1–2 / 0-1 scale referenced in
`_planning/2026-27-scope-and-sequence.md`'s Formative Assessment System section — see that doc
for the full formative design (F1–F6, the Exit Ticket Bank).
