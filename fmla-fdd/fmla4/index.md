# Unit 4 | GMetrix Illustrator 2: Dobson National Park Branding Style Guide (Nov 4 – Dec 1, 2026)

## Introduction

Module 2 introduces the running client, Dobson National Park. You build its branding style guide: color codes (HSB, RGB, CMYK, HEX), swatches, type classifications, visual hierarchy, logo usage and logo no-gos.

This unit replaces the regular Foundations of Digital Design Unit 4 lessons while your teacher is on leave. Every class follows the same routine: a stinger, a pace check, then self-paced work in BrainBuffet Illustrator Module 2.
