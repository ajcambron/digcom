# S | 9 | Magnum Opus Photography Portfolio

{: .note }
**Existing project, lightly edited.** From the current PDD course: EX44 Magnum Opus TSA Portfolio (outline), EX45 Cumulative Google Sites Portfolio. Draft revision page; the original files are untouched.

The culmination of this unit. You'll curate and present a five-image photography portfolio with statements in TSA's format.

## Project Briefing (~10 min)

Teacher shows the TSA order and a sample portfolio, then start your own.

## Project Work Time (~53 min)

### Deliverables checklist

- [ ] **Five images**: color, B&W, macro, still life, student choice.
- [ ] **Statements** for each.
- [ ] **Theme summary.**
- [ ] **References.**
- [ ] **Web page.**

{: .discussion }
**Check-in:** Peer review of image statements against the TSA statement requirements before final assembly.

{: .important }
**Competition track (optional enrichment):** TSA submission; two mounted SkillsUSA prints; résumé; mock interview.

## Save, Export & Submit (~5 min)

{: .reflection }
A two-minute presentation of one image: settings, edits, and how it fits the theme.
