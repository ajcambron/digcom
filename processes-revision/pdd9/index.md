## Introduction

Unit 9 closes the ACP content and assembles the year's work. Students learn the client-side and delivery objectives (briefs, scope, export formats, file management), then curate the Magnum Opus: a five-image portfolio in TSA's format that every student completes, with print mounting and the interview as competition-track extensions.

## Core vs. Competition Track

- **Core (everyone):** Everyone builds the 5-image TSA-format portfolio PDF and a portfolio web page.
- **Competition track (enrichment):** TSA submission package (copyright checklist, releases, references), two mounted SkillsUSA prints, résumé, and a mock interview.

## Literacy & Numeracy

- **Literacy:** Design briefs, image statements, résumé and cover letter; interview practice with sentence frames.
- **Numeracy:** 11×14 at 300 ppi = 3300 × 4200 px; mat-window math (16×20 board, 11×14 window, borders); file-size budgets for web.

## Learning Outcomes

Upon successful completion of this unit, you will be able to:

- Read a brief, write a project plan, and manage scope and files
- Export images for web and print with the right format, color space, and bit depth
- Prepare a portfolio page that meets accessibility basics (alt text, contrast)
- Present a curated portfolio and explain each image's settings and edits
