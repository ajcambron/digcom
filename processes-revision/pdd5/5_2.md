# 5.2 | Content-Aware Fill & Healing

{: .note }
**Existing lesson, lightly edited.** From the current PDD course: EX26 Content-Aware Fill. Draft revision page; the original files are untouched.

Today you'll learn to make distractions disappear.

## Stinger (~10 min)

{% include lesson-parts/stinger.md %}

## Direct Instruction (~10 min)

**Spot Healing** fixes small spots automatically. **Healing Brush** and **Clone Stamp** copy from a source you choose (Option-click). **Patch** drags a selection to a clean area. **Content-Aware Fill** fills a selection using the surroundings. The **Remove** tool brushes over objects to erase them. Work on a new layer with 'Sample All Layers' on.

> "See the repeating bricks? That's a clone giveaway. Change the source often."

**Scaffolded questions. Cold-call through all three:**

> **Recall:** "Which tool needs an Option-click source?"

> **Analysis:** "Why would Content-Aware Fill fail on a busy, patterned area?"

> **Synthesis/Extension:** "Is removing an object okay in a news photo? A contest photo? An ad?"

## Guided Practice (~23 min)

1. **Fix the five distractions**, each with its suggested tool.
2. **Work on a blank layer** with Sample All Layers checked.
3. **Turn and Talk:** which tool was fastest? Which was cleanest?
4. **Try one fix** on your own photo.

{: .discussion }
Should TSA or SkillsUSA judges know which objects you removed? Why?

## GMetrix/BrainBuffet (~30 min)

Log in and keep working in your BrainBuffet module: BrainBuffet Photoshop Module 2 (Retouch or Real), ~2 h. Start wherever you left off.
