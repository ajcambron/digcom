# S | 5 | Original Panorama

{: .note }
**Existing project, reordered, content unchanged.** From the current PDD course: EX23 Panorama + Panorama Assignment. Draft revision page; the original files are untouched.

The culmination of this unit. You'll shoot and merge an original panorama and repair its edges with Content-Aware Fill and healing tools.

## Project Briefing (~10 min)

Teacher demos Photomerge and edge repair, then start your own.

## Project Work Time (~53 min)

### Deliverables checklist

- [ ] **Original sequence** with 25–40% overlap.
- [ ] **Merged panorama** (Photomerge).
- [ ] **Repaired edges** on separate layers.
- [ ] **Repair log.**

{: .discussion }
**Check-in:** Partners spot each other while shooting on campus and check overlap on the LCD before moving on.

{: .important }
**Competition track (optional enrichment):** TSA draft portfolio checkpoint: choose five category candidates and draft one statement; SkillsUSA résumé draft.

## Save, Export & Submit (~5 min)

{: .reflection }
Reflection: which repair was hardest, and how would you shoot differently to avoid it?
