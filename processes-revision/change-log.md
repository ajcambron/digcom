# Change Log

{: .warning }
**Draft revision (unlisted).** Part of the first-draft PDD course revision. The live [Processes of Digital Design](../processes/index.md) pages and the Drive originals are unchanged. See the [revision overview](index.md).

Compared with the existing PDD course (Drive folder *Processes of Digital Production*, the 2023 course outline, and the current syllabus's 8-unit list).

## Structure

| Change | Reason |
|---|---|
| 8 topic units → 9 core units + Unit 10 (ACP exam) + 2 Extra Units | Matches the FDD/ADD calendar math and puts the exam in its own unit with review and practice-exam time before it. |
| Every unit is 4 formative lessons + 1 summative, with `lesson:` front matter and paired teacher pages | Same format as FDD and ADD, so teacher pages, exit tickets, the vocab quiz, and the calendar all work automatically. |
| GMetrix/BrainBuffet strand added from Unit 2 on (30 min per formative lesson) | The current PDD course has no ACP practice structure; FDD and ADD do. |
| Lighting, B&W, still life, and macro moved before winter break (Unit 4) | Competition skills both events judge are covered in rudimentary form before Christmas. |

## Added (NEW lessons)

8 of 36 formative lessons; no NEW summatives.

| Lesson | Why it's needed |
|---|---|
| [2.1 GMetrix Setup & ACP Pre-Test](pdd2/2_1.md) | A port of FDD 2.1 and ADD 2.1 with Photoshop in place of Illustrator/Premiere Pro. The existing PDD course has no GMetrix day; this gives students the same baseline the other two courses get before BrainBuffet Module 1. |
| [2.4 Selection Tools](pdd2/2_4.md) | No existing PDD lesson teaches the selection tools directly, but ACP 5.1.a names them all (marquee, lasso, Quick Selection, Magic Wand, Object Selection, Select Subject/Sky, Selection Brush, Color Range). Built on Classroom in a Book's selections chapter, which is already in the Drive Photoshop folder. |
| [4.4 Still Life & Macro](pdd4/4_4.md) | TSA requires a macro image and a still-life image in every portfolio, and the semifinal shoot can include product shots; nothing in the existing course teaches either. |
| [7.4 Generative AI Tools & the Ethics Line](pdd7/7_4.md) | ACP 4.1.c (generative AI prompts, Generative Fill/Expand, Sky Replacement) and 1.2.a (AI-generated content) have no existing coverage. TSA's honor statement bans generative AI in portfolio images, so this lesson teaches the tools for the exam and draws the line for competition work. |
| [8.4 Vector Shapes, the Pen Tool, Frames & Vector Masks](pdd8/8_4.md) | ACP 4.2.a (Pen and shape tools), 3.2.c (Frame tool), and 3.2.d (vector masks) have no existing coverage in the PDD course. Comes right before S8's Google Doodle, which uses all three. |
| [9.1 Client Communication & Project Management](pdd9/9_1.md) | ACP 1.1.c (communicating design plans) and 1.1.d (project management: scope, scope creep, timelines, file management) have only a light touch in 3.1. Also prepares the TSA interview and SkillsUSA job interview. |
| [9.3 Save, Export & Nondestructive Workflow](pdd9/9_3.md) | ACP Domain 6 (Export Layers/Artboards, Quick Export, Export As, save formats, color space, bit depth) and linked Smart Objects/packaging (2.3.a) aren't taught directly anywhere in the existing course. |
| [9.4 Print Presentation: Mounting, Matting & the Portfolio PDF](pdd9/9_4.md) | SkillsUSA requires 11×14 prints mounted on 16×20 foam core with a 16×20 black mat and an 11×14 window; TSA requires a specifically ordered PDF portfolio. Neither is taught in the existing course. |
