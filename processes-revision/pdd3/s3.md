# S | 3 | Event Photojournalism Package

{: .note }
**Existing project, lightly edited.** From the current PDD course: EX11 Event Photography. Draft revision page; the original files are untouched.

The culmination of this unit. You'll cover an event and deliver five edited, captioned images plus a contact sheet.

## Project Briefing (~10 min)

Teacher demos Camera Raw basics and making a contact sheet, then start your own.

## Project Work Time (~53 min)

### Deliverables checklist

- [ ] **Contact sheet** of the whole shoot.
- [ ] **Five edited images** covering the shot types.
- [ ] **Five cutlines.**
- [ ] **Releases** for any recognizable subject in a promotional use.

{: .discussion }
**Check-in:** Editor-and-photographer pairs choose the final five together.

{: .important }
**Competition track (optional enrichment):** SkillsUSA K4: a 45-minute timed theme shoot as practice.

## Save, Export & Submit (~5 min)

{: .reflection }
Reflection: which frame tells the story best, and why?
