# S | 2 | About Me

{: .note }
**Existing project, reordered, content unchanged.** From the current PDD course: EX04 About Me. Draft revision page; the original files are untouched.

The culmination of this unit. You'll design an About Me graphic using a saved preset, organized layers, placed images, clean selections, and live type.

## Project Briefing (~10 min)

Teacher shows an exemplar About Me file with its Layers panel open, then start your own.

## Project Work Time (~53 min)

### Deliverables checklist

- [ ] **Five facts** about you, each with an image.
- [ ] **Selections** used to isolate at least two images.
- [ ] **Named, grouped layers.**
- [ ] **Live type** with a clear hierarchy.
- [ ] **Saved PSD and exported JPEG.**

{: .discussion }
**Check-in:** Midpoint peer check: partners check the Layers panel for names and groups.
