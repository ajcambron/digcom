# 2.4 | Selection Tools

{: .highlight }
**NEW lesson (stub).** No existing PDD lesson covers this. Written for the draft revision; materials marked "Stub" in the teacher notes still need to be built.

Almost every edit starts with a selection. Today you'll learn which tool to grab for which job.

{% include lesson-parts/stinger.md %}

## Direct Instruction (~10 min)

Geometric shapes: **Marquee**. Freehand: **Lasso** and **Polygonal Lasso**. Clear edges: **Quick Selection** or **Object Selection**. A whole person: **Select → Subject**. A sky: **Select → Sky**. One color: **Magic Wand** or **Color Range**. Hold **Shift** to add and **Option** to subtract. Click **Select and Mask** to clean up the edge.

> "The best selection tool is the one that does the most work for me. For a person, I try Select Subject first, then fix what it missed."

**Scaffolded questions. Cold-call through all three:**

> **Recall:** "Which tool selects everything of one color?"

> **Analysis:** "Why might Select Subject fail on a photo of a person in front of a crowd?"

> **Synthesis/Extension:** "Plan the fastest way to select a blue car in a parking lot full of cars. Which tools, in what order?"

## Guided Practice (~23 min)

1. **Open** the challenge file. Each subject is on the Background layer.
2. **Think-Pair-Share:** pick a tool for each subject before trying.
3. **Select and copy** each subject to its own layer (⌘J), named for the tool you used.
4. **Refine one edge** in Select and Mask and compare with your partner.

{: .discussion }
Which subject was hardest to select, and what tool finally worked?
