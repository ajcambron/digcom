# 2.2 | Workspace, Documents & Navigation

{: .note }
**Existing lesson, lightly edited.** From the current PDD course: EX01 Welcome Back Graphic. Draft revision page; the original files are untouched.

Before you edit a single photo, set up the file right. Today you'll build your Welcome Back Graphic and learn to get around Photoshop.

## Bell Ringer / Hook (~10 min)

{: .discussion }
A poster and an Instagram post need different files. Name one setting that should be different.

## Direct Instruction (~10 min)

Every Photoshop file starts in **File → New**. Choose the size in pixels or inches, the **resolution** (300 ppi for print, 72 is fine for screens), and the **color mode** (RGB for screens, CMYK for print). Save the settings as a **preset** so you never set them up twice. Then learn to move around: **Hand** (hold Space), **Zoom** (Z), **Rotate View** (R), and **rulers** (⌘R) with **guides** dragged from them. **Preferences** (Photoshop → Settings) control things like units and the number of undos.

> "I don't eyeball my margins. View → Guides → New Guide Layout, type the number, and it's exact."

**Scaffolded questions. Cold-call through all three:**

> **Recall:** "What color mode would you use for a printed poster?"

> **Analysis:** "Why save a preset instead of typing the settings each time?"

> **Synthesis/Extension:** "Design the preset you'd want for a yearbook spread. What settings, and why?"

## Guided Practice (~23 min)

1. **New document:** 8 × 10 in, 300 ppi, RGB. Save it as a preset named 'PDD 8x10 Print'.
2. **Rulers and guides:** turn on rulers, set units to inches in Preferences, and add a 0.5 in margin with New Guide Layout.
3. **Build the graphic:** place your name and one image into the Welcome Back layout.
4. **Navigate:** zoom to 300%, pan with Space, rotate the view 15°, then reset it (Esc). Show your partner.

{: .discussion }
Which navigation shortcut do you think you'll use most? Why?
