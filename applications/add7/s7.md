# S | 7 | Short Film

Everything from Unit 7 becomes real today. Bring your script, storyboard, call sheet, releases,
and budget, you're either filming or editing against them, not starting from scratch.

## Project Briefing (~10 min)

{: .highlight }
A call sheet only works if everyone actually checks it. Review today's before anyone touches a
camera: which scenes, which cast/crew, and what needs to be done by the end of the period.

{% include camerasetup.md %}

## Project Work Time (~23 min)

1. **If filming today:** follow the call sheet's scene order. Apply deliberate camera technique
 (not default framing) for every shot on the list.

{% include production.md %}

2. **If editing today:** assemble footage already shot into your sequence, following your
 storyboard's shot order.

{% include organizevideo.md %}

3. **Continuity check:** before moving to the next scene, verify props, costume, and character
 position match the previous shot of the same scene.
4. **Update the plan-of-work log:** what actually got filmed or edited today, versus what the
 shooting schedule planned.
