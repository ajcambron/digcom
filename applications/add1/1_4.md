# 1.4 | Two-Column Script

## Introduction
For this assignment, you will create a two-column script to plan your explainer video shoot. A two-column script separates visual/video description (left column) from audio/dialogue (right column) — the standard format for planning informational and documentary-style video, and the foundation for the shot list you'll mark up in [1.5 | Film Form & Shot Vocabulary]({% link applications/add1/1_5.md %}).
