# 9.3 | Export & Media Encoder

## Key Terms

{: .vocab }
{% include vocab/add-export-encoding.md %}

Every export you've done so far used the same H.264 settings. Today's about why that choice was
right for those projects, and what changes when the delivery scenario doesn't.

## Direct Instruction (~10 min)

{% include worksheet.html file="guided-notes-9-3" title="9.3 Guided Notes: Export & Media Encoder" presentation="/assets/presentations/add9-3.html" %}

A **codec** (H.264, ProRes) is the compression algorithm; the file format (.mp4, .mov) is just
the container it travels in. Export a graphic or title that needs to layer over other footage
with its **alpha channel** preserved, or the transparency is lost. **Quick Export** is fine for a
fast, simple delivery with no special settings. For anything more, **Adobe Media Encoder**'s
**queue** lets you send multiple export jobs and keep editing while they render in the
background, real **batch processing** instead of babysitting one export at a time.

{% include exportvideo.md %}

> "'Match Source' isn't a lazy default, it's usually the right call: it keeps your export as
> close to your original footage's quality as possible without you having to guess settings."

**Scaffolded questions. Cold-call through all three:**

> **Recall:** "What's the difference between a codec and a file format?"

> **Analysis:** "Why would exporting a title graphic without its alpha channel break a compositing
> workflow?"

> **Synthesis/Extension:** "You need to deliver the same project as a small web file AND a
> full-quality archive master. What's different about those two exports?"

## Guided Practice (~23 min)

1. **Choose a finished sequence** from an earlier project.
2. **Export version 1**: a web-delivery version (H.264, Match Source or a high-quality preset).
3. **Export version 2**: a different scenario (archive master, or a graphic with alpha channel
 preserved), with settings matched to that scenario.
4. **Queue both** in Adobe Media Encoder rather than exporting one at a time through Premiere.
5. **Small-group report-out:** which settings did your group choose for your assigned scenario,
 and why?

{: .discussion }
Why isn't "just use the default settings" a safe strategy for every delivery scenario?
