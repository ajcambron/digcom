# Unit 9 | Publishing & Delivery

## Introduction

A finished edit isn't actually finished until it's checked, reframed for wherever it's going,
exported correctly, and archived so it can be found again. This unit is the last mile between
"the edit is done" and "the video is actually out in the world."

{% include unit-video.html %}

## Learning Outcomes

Upon successful completion of this unit, you will be able to:

- Quality-check a sequence for gaps, audio levels, and safe margins before export
- Use Auto Reframe to deliver a sequence in multiple aspect ratios for different platforms
- Export through Adobe Media Encoder, including batch processing multiple versions at once
- Archive a finished project using Premiere's Project Manager
