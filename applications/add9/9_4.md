# 9.4 | Archiving with the Project Manager

## Key Terms

{: .vocab }
{% include vocab/add-asset-management.md %}

A project you can't reopen cleanly in a year isn't archived, it's just saved somewhere. Today's
about making sure it actually is what it looks like.

## Direct Instruction (~10 min)

{% include worksheet.html file="add9-archiving-reference" title="9.4 Guided Notes: Archiving" presentation="/assets/presentations/add9-4.html" %}

Premiere's **Project Manager** is the tool for this. **Collect Files** copies only the media a
sequence actually uses (not your whole raw-footage folder) into a new, self-contained project.
**Consolidate and transcode** goes further, converting everything into one standard format so an
archive isn't a patchwork of codecs a future machine might not support. Before you delete
anything from the original location, **verify** the archive by actually reopening it and checking
for **offline media**, any clip Premiere can't find is a broken archive, not a finished one.

> "An archive nobody's ever tested by actually reopening it isn't an archive, it's an assumption.
> Test it before you delete the original."

**Scaffolded questions. Cold-call through all three:**

> **Recall:** "What's the difference between Collect Files and consolidate and transcode?"

> **Analysis:** "Why would skipping the verification step (actually reopening the archive) be
> risky, even if Project Manager reported success?"

> **Synthesis/Extension:** "You're archiving a project for a client who might reopen it on a
> completely different computer in two years. What does that change about your approach?"

## Guided Practice (~23 min)

1. **Choose a finished project** from an earlier unit.
2. **Run Project Manager**: Collect Files, then consolidate and transcode.
3. **Reopen the archived version** in a new location (or have a partner open it) and check for
 offline media.
4. **Fix anything broken** before calling the archive complete.
5. **Partner check:** swap archived projects and confirm each other's reopens with zero offline
 clips.

{: .discussion }
What would a stranger (or future you) need to see in this archive to trust it's actually
complete?
