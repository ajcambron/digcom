# 12.1 | Talent & Location Documentation

## Key Terms

{: .vocab }
{% include vocab/add-visual-reference.md %}

If your Short Film needed a reshoot next month, could your group match every costume and every
location exactly? That's the whole reason this documentation exists.

## Direct Instruction (~10 min)

{% include worksheet.html file="add12-talent-location-reference" title="12.1 Guided Notes: Talent & Location Documentation" presentation="/assets/presentations/add12-1.html" %}

A **continuity photo** captures a cast member in costume, or a location's exact setup, before
filming, so if a scene has to be reshot (a different day, a different week), everything can be
matched precisely. A **visual reference** board collects images (film stills, photography,
paintings) that helped the team agree on a shared look before a single frame was shot, useful
documentation of why the film looks the way it does, not just what it looks like.

> "Documentation done after the fact is a guess. Documentation done before filming is a record.
> The value is entirely in the timing."

**Scaffolded questions. Cold-call through all three:**

> **Recall:** "What's the difference between a continuity photo and a visual reference image?"

> **Analysis:** "Why would a production team bother photographing an empty location before
> anyone's even arrived to shoot there?"

> **Synthesis/Extension:** "A year from now, someone wants to remake your Short Film's opening
> scene exactly. What in today's documentation would help them most?"

## Guided Practice (~23 min)

1. **Photograph each cast member** in costume (or gather existing photos from Unit 7's shoot).
2. **Photograph each key location** used in the film.
3. **Build a visual reference board**: 4-6 images that shaped the film's actual visual style.
4. **Label everything** clearly. which cast member, which location, which reference informed
 which creative choice.

{: .discussion }
What would be lost if this documentation didn't exist and your group had to reshoot a scene next
year?

## Studio/Project Work Time (~30 min)

Organize today's documentation into your Production Book's Art section, ready to be printed and
filed later this unit.

Save your file, then screenshot your organized documentation.
