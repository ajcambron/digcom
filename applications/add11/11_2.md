# 11.2 | Suns and Moons

## Key Terms

{: .vocab }
{% include vocab/add-after-effects-basics.md %}

A day/night cycle that loops has to solve a problem 11.1 didn't: the end has to match the
beginning exactly, or the seam shows every time it repeats.

## Direct Instruction (~10 min)

{% include worksheet.html file="guided-notes-11-2" title="11.2 Guided Notes: Suns and Moons" presentation="/assets/presentations/add11-2.html" %}

A **cyclical animation** loops back to its starting state, a sunrise-to-sunset-to-sunrise cycle,
a spinning logo, a pulsing icon. The hard part: every property that's keyframed (position, scale,
opacity, rotation) has to return to the exact same value it started at, or the loop visibly
jumps. **Precomposing** groups multiple animated layers (the sun, the moon, the sky color) into
one nested composition, so the whole cycle can be treated, retimed, or reused as a single unit.

> "A loop doesn't have to be short to feel seamless, and it doesn't have to feel seamless just
> because it's short. It's seamless because every value matches at the seam, nothing more."

**Scaffolded questions. Cold-call through all three:**

> **Recall:** "What has to be true about a keyframed property for a loop to feel seamless?"

> **Analysis:** "Why might precomposing the sun/moon cycle make it easier to reuse in a different
> project later?"

> **Synthesis/Extension:** "Your loop is 4 seconds and needs to feel calm, not busy. What would
> you change about your keyframe timing to achieve that?"

## Guided Practice (~23 min)

1. **Open the provided sun/moon shape template.**
2. **Keyframe the sun's arc** across the sky, fading out as the moon fades in.
3. **Keyframe the moon's arc** the same way, completing the cycle back to the sun's starting
 position.
4. **Check the loop point**: does position, opacity, and scale all match exactly at the seam?
5. **Small-group troubleshoot:** each group checks one classmate's loop for a visible jump.

{: .discussion }
What made a loop feel seamless, and what gave a non-seamless one away?

## Studio/Project Work Time (~30 min)

Precompose your sun/moon cycle into a single nested composition. Add a second looping element
(drifting clouds, twinkling stars) that complements the cycle without breaking its seam.

## Exit Ticket / Wrap-Up (~5 min)

Save your file, then screen-record or export a short loop of your animation.
