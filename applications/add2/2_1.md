# 2.1 | Projects, Sequences & Bins

## Key Terms

{: .vocab }
{% include vocab/add-premiere-project-setup.md %}

Every project you'll build this year starts the same way: a new Premiere project, a sequence
that matches your footage, and a clear bin structure — before you ever make a single cut. Skip
this step and you'll spend the rest of the project fighting disorganized files instead of editing.

## Direct Instruction (~10 min)

{% include worksheet.html file="add2-project-setup-checklist" title="2.1 Guided Notes: Projects, Sequences & Bins" presentation="/assets/presentations/add2-1.html" %}

> "Every Premiere project starts with the same question: what format is my footage actually in?
> Your sequence settings should match your footage, not the other way around — that's what a
> sequence preset is for."

Walk through: **File > New > Project** (naming, project settings, scratch disk location) → import
footage → **File > New > Sequence** (choosing the preset that matches the footage's frame size and
frame rate) → the Project panel and its bins → Source Monitor (previewing a raw clip) vs. Program
Monitor (previewing the sequence).

**Scaffolded questions — cold-call through all three:**

> **Recall:** "What's the difference between the Source Monitor and the Program Monitor?"

> **Analysis:** "Why does it matter if your sequence preset doesn't match your footage's frame
> rate?"

> **Synthesis/Extension:** "If you were handed a hard drive of 50 unsorted clips, what bin
> structure would you build before touching the timeline, and why?"

## Guided Practice — Project Setup (~23 min)

1. **Create a new project**, name it correctly (`LastName_FirstName_Unit2`), and confirm your
   scratch disks point to your project folder, not the OS drive.
2. **Import the provided sample footage** into the Project panel.
3. **Create at least 3 bins** (e.g. A-Roll, B-Roll, Audio) and sort every imported clip into the
   correct one.
4. **Create a new sequence** using the preset that matches your footage's actual specs — check the
   Properties panel on a clip first if you're not sure.
5. **Turn and Talk:** compare bin structures with a partner — did you organize by the same
   categories?

{: .highlight }
If Premiere warns your sequence settings don't match your footage, don't ignore it — that
mismatch is exactly what today's lesson is about.

{: .discussion }
**Cold call check:** you open a project six weeks from now and every clip is just named
`IMG_0001.mov` through `IMG_0347.mov` with no bins. What's the actual cost of that, in time?
