# Unit 2 | Editing in Premiere

## Introduction

Your first formal look at Adobe Premiere Pro — setting up a project and sequence correctly,
navigating and assembling a timeline, applying continuity-editing techniques, and understanding
the video standards and formats behind every clip you import — building toward editing a real
scene from a television show.

{% include unit-video.html %}

## Learning Outcomes

Upon successful completion of this unit, you will be able to:

- Set up a Premiere project with correct settings and an organized bin structure
- Navigate a timeline and assemble a rough cut using Insert, Overwrite, Lift, and Extract
- Apply continuity-editing techniques (L/J cuts, match cuts, cutaways) to smooth a sequence
- Identify a clip's frame rate, resolution, and codec, and explain why they matter
