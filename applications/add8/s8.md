# S | 8 | Edit Polish Project

You already made this edit once. Today you make it better, on purpose, using the judgment,
pacing, and technical skills this unit built.

## Project Briefing (~10 min)

{: .highlight }
This isn't a redo from scratch. Open your original Television Scene Edit or Video Essay project
and identify specifically what needs polish: pacing that drags, a shot that could use a transform
or speed effect, a project panel that was never organized.

## Project Work Time (~23 min)

1. **Re-cut for pacing**: identify at least one stretch of the sequence that drags or rushes, and
 fix it using 8.2's shot-length/rhythm principles.
2. **Apply one transform or speed effect** purposefully (reframe, rotation, time remapping, or
 freeze frame), from 8.3.
3. **Organize and archive** the project using 8.4's bins/labeling/naming convention, then export
 an archive with Project Manager.
4. **Plus/Delta peer review**, comparing the original cut to today's polished version:

{% include peerreview.md %}

5. **Apply your Revision Plan**, prioritizing the changes that most improve pacing or clarity.

{: .discussion }
What did re-cutting this project reveal about the original edit that wasn't obvious the first
time you made it?
