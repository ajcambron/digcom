# Unit 8 | The Editor's Toolkit: Pacing, Polish & Professional Practice

## Introduction

Four skills that never got their own unit, because your earlier summatives didn't require them,
but a working editor uses constantly: knowing what an editor's job actually is, controlling
pacing on purpose, transform/speed effects, and keeping a project's files organized enough that
you (or someone else) can open it again in a year and understand it.

{% include unit-video.html %}

## Learning Outcomes

Upon successful completion of this unit, you will be able to:

- Describe what editorial judgment actually is and how it differs from simply assembling clips
- Control a sequence's pacing deliberately, using shot length and rhythm to shape tension
- Apply transform and speed effects (scale, rotation, time remapping, freeze frame) purposefully
- Archive a finished project using Premiere's Project Manager and a consistent naming convention
