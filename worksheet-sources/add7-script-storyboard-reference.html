beat  •  parenthetical  •  scene heading  •  shot list  •  slugline  •  storyboard  •  two-column script
  • 📜
    Slugline order Special info → INT./EXT. → location → shot type → subject → time of day.
  • 🎭
    Format spec Courier or Courier New, 12pt. 1" margins on description, 2" inset on dialogue.
  • 💬
    Parenthetical A short delivery note in parens under a character's name. Use sparingly.
  • 📝
    Shot list Every shot the camera needs, numbered in order. 15–30 shots for a 2–6 min film.
  • 🎭️
    Storyboard panel Shot type, camera movement, action summary, dialogue/sound cue.
  • ⏳
    Beat A pause or turning point marked in the script to control pacing.
ALL CAPS in a script: a speaking character's first-appearance name, sound effects/off-screen sounds, and camera direction. Nothing else.
