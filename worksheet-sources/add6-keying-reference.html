ADD 6.3 · Applications of Digital Design
Name
Date
chroma key  •  luma key  •  spill  •  Ultra Key
  1. Apply Ultra Key to the green screen clip.
  2. Sample the key color to remove the background.
  3. Suppress spill around edges, especially hair.
  4. Add and scale/position a new background so the composite looks intentional.
Spill suppression is what separates an amateur composite from a clean one. That green glow around hair or shoulders is the first thing a viewer's eye catches.
