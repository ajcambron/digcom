FDD 9.3 · Digital Communications
Name
Date
  • 💾
    Embedding Copies the image's full pixel data into the document. File grows larger, but it never breaks if the original moves or is deleted.
  • 🔗
    Linking Places a reference to an external file, shown at preview resolution. Keeps the .ai file small, but breaks ("missing") if the original moves, is renamed, or is deleted.
  • ⚠
    Missing / Modified (Links panel icons) A yellow warning icon means the link is missing or the source changed since it was placed — check the Links panel regularly.
  • 🔄
    Relink In the Links panel, points a broken link back to the (possibly moved or renamed) source file.
  • ✎
    Edit Original Reopens the source file in its original application. Save your change there, and the placed image updates automatically back in Illustrator.
Rule of thumb: link when file size matters and you'll keep the source nearby; embed when you need the file to never break, even if it means it's bigger.
