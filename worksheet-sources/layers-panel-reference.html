Layers Panel Reference

FDD 7.1 · Digital Communications
Name
Date
  • 📁
    New Layer Adds a new top-level layer to organize objects into. Double-click its name to rename it — always use a real name, never leave it as "Layer 1."
  • ↳
    Sublayer Every path, group, or object automatically gets its own sublayer nested inside its layer. Expand the disclosure triangle to see and rename them.
  • ↕
    Reorder (Stacking Order) Drag a layer or sublayer up or down in the panel list. Higher in the list = further in front, visually.
  • 🔒
    Lock / Unlock Click the lock column to prevent a layer from being accidentally selected or edited. Click again to unlock it.
  • 👁
    Show / Hide Click the eye icon to temporarily hide a layer's contents from view (and from printing/export) without deleting anything.
  • ⊞
    Merge Selected vs. Flatten Artwork Merge Selected combines only the layers you've selected, keeping stacking order intact. Flatten Artwork collapses the entire document into one layer — use it only when you're completely done organizing.
Reminder: the target icon on the far right of a layer's row selects every object in that layer at once — useful before locking, hiding, or moving a whole group.
