  1. A color is a saved color built from CMYK or RGB percentages — the standard, everyday swatch.
  2. A swatch represents a single pre-mixed ink (see 3.1's Spot Color) — use it when an exact brand color matters.
  3. A swatch is linked everywhere it's used: edit the swatch once, and every shape using it updates automatically — a huge time-saver for a client's brand color used across many objects.
  4. The Color Guide panel takes one base color and suggests whole harmonious groups from it (complementary, analogous, triadic...) — the same relationships from 3.1's color wheel, generated for you.
gradient
gradient
  1. Each colored point along a gradient's ramp is a — drag to reposition it, double-click to change its color, or drag its opacity slider down to fade it out.
  2. A Gradient Mesh lets you blend many colors across a shape along a flexible grid of points, instead of a straight line or circle — useful for photorealistic shading, but the most advanced gradient tool.
