Part 1 · Log in to GMetrix SMS
  1. Open GMetrix SMS (Applications folder → GmetrixSMSe).
  2. Click the Login with Google button and sign in with your school Google account. Don't create a new account.
Part 2 · Enter our class code (first time only)
  1. Find the code on Schoology: open our class's Schoology homepage and scroll to How to Contact Me. The code is on the Gmetrix: line.
  2. In GMetrix SMS, click Redeem Code in the left sidebar, type the code exactly (including the dash), and click Redeem Code.
Part 3 · Pre-launch setup (every time you log on to a computer)
Be patient: steps 8–10 each ask for an administrator password. Raise your hand and wait. Your teacher has to type it on every computer in the room, one at a time.
  1. Open the Creative Cloud app → Apps → Installed apps. Next to Premiere Pro's Open button, click ••• (More actions) → Open in Rosetta.
  2. When Premiere Pro opens, check that the GMetrix extension loaded: Window → Extensions should list GMetrix. Not there? Tell your teacher.
  3. Quit Premiere Pro (⌘ Command + Q).
  4. In GMetrix SMS, open Settings → Tasks tab → Delete Test Resource Archive → Execute.
  5. Click the Plugins tab → Premiere Pro → Install Premiere Pro Plugin → Execute.
  6. On the same page: Reinstall Premiere Pro Plugin Workspace Files → Execute.
Part 4 · Launch the Premiere Pro practice exam
  1. In your list of tests, find the Adobe Certified Professional: Premiere Pro practice exam (2025 exam version) and select it.
  2. Choose Testing Mode and start the exam. GMetrix opens Premiere Pro for you.
  3. Wait for the GMetrix panel to appear in Premiere Pro with your first task. Don't click anything while it loads.
  4. Work the whole exam independently, then submit it. On the results screen, press ⌘ Command + Shift + 3 to screenshot the whole screen. It saves to your Desktop; move it to your Screenshots folder.
Troubleshooting
ProblemTry this
Can't log in Use Login with Google and pick your school account, not a personal one.
"Invalid code" Re-type it from Schoology exactly, including the dash. Still invalid? Tell your teacher.
GMetrix panel never appears, or the exam won't start Quit Premiere Pro (⌘Q), redo Part 3 (steps 5–10), then start the exam again.
Exam looks frozen at the start of a question Premiere is converting the sample project files. Let it finish; it doesn't count against the timer.
Can't find the Premiere practice files Finder → Go > Go to Folder (⇧⌘G) → /Users/Shared/GMetrix. Read-only: copy files to your own folder first.
GMetrix SMS says it can't find Premiere Pro Tell your teacher.
